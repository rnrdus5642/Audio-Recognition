# 실제 발음 라벨 비교 학습의 계획과 후속 권고

**이 문서는 당시 계획과 권고를 보존한다.** 현재 우선순위·실행 상태는
[작업 현황](CHILD_JAMO_STATUS.md)을 따른다. 이후 전체 자모 원인 분석과 무음·음량
추가 학습 비교를 완료하고 기존 모델의 마이크 테스트 페이지를 만들었다.
아래 6개 적합도 후속 비교 학습은 실행하지 않았다.

2026-09-27 갱신: 아래 계획에 따른 청취 20개와 두 조건의 비교 학습을 완료했다.
청취 라벨 조건은 학습 6개에서 3개→4개 일치했지만, 다른 화자 4개와 원래 진단은
개선하지 못했다. `쌕→책` 오판도 생겨 **후보는 채택하지 않는다.** 현재 추가 청취와
실행 중인 학습은 없다. [완료 결과와 한계](CHILD_JAMO_LABEL_COMPARISON_2026-09-27.md)를 따른다.

당시 후속 권고는 기존 청취 6개로 선택 라벨의 학습 적합도와 기존 음성 혼합의 영향을
분리해 확인하는 것이다. 이후 원래 문제의 자음 대조를 포함하도록 학습·평가 자료를
설계한다. 아래는 이번 비교를 시작할 때의 근거와 계획이며, 추가 실험 실행 상태가 아니다.

당시 추천한 단계는 **실제 발음이 확인된 자료를 소규모로 확보한 뒤, 같은 음성에
붙이는 라벨만 다르게 한 비교 학습**이다. 이번에 다름을 보고한 4개를 삭제하고 기존
학습을 반복하는 것만으로는 원래 오류의 원인이나 해결 효과를 충분히 검증할 수 없다.

## 이 방향을 추천하는 근거

1. 청취 18개 중 4개에서 다름이 보고됐고, 그중 3개는 원본 전체 PCM과 문구를 그대로
   사용했다. 우리 자르기나 G2P의 문자 변경 이전부터 전사와 청취가 어긋난 근거다.
   정확한 실제 발음열을 새로 얻은 것은 아니다.
2. 기존 모델은 다름 4개 중 3개를 전사대로 출력했다. 기존 모델과 전사의 일치만으로
   실제 발음 라벨의 정확성을 확인할 수 없다.
3. 음높이·속도 증강의 두 비교 학습은 원래 문제를 고치지 못했다. 계획 당시에는 라벨의
   효과를 분리해 시험하지 않았으므로, 증강 학습을 더 반복하기 전에 이 가설을 검증했다.

## 이번에 추가로 확인한 자료

원래 학습 150,253개에 해당하는 제공 JSON을 모두 읽었다. 파일 누락·중복·파일명이나
정규화 전사의 불일치는 0개다. `ErrorTagged`, `GrammaticalError`는 모두 `N/A`,
`QualityStatus`는 모두 `Good`이다. 11개에만 있는 `AccurateRead`, `SpeakerRead`,
`ErrorWords`, `CausesofError`도 실제 내용은 모두 `N/A`다. 따라서 **선택된 학습 자료의
이 필드들에 사용 가능한 발음 오류 주석이 있는데 우리가 버렸다는 근거는 없다.**
`N/A`와 `Good`이 올바른 실제 발음을 뜻하는 것은 아니다.

반면 현재 학습·검증 화자에 속한 5~7세의 미사용 인덱스에서 괄호 표기 후보를 찾았다.
테스트 화자는 이번 탐색에 넣지 않았다.

| 인덱스 범위 | 괄호·대괄호 포함 파일 | 앞말과 다른 한글 표기가 인접한 후보 |
|---|---:|---:|
| 현재 학습 화자 | 3,999 | 3,793 |
| 현재 검증 화자 | 1,182 | 1,107 |

예: `일어나요(인어나요)`, `꽃을(꼬를)`, `팔짝팔짝(팔닥팔짝)`.
이 표기들은 현재 지원하지 않는 문자 규칙에 걸리고 기존 학습·검증 목록에 없다.
그러나 괄호는 삽입·수정·반복을 나타내기도 한다. 위 숫자는 발음 오류의 확정 수나
사용 가능한 학습 파일 수가 아니다. 원본 음성 가용성과 실제 발음 여부는 별도 확인한다.
**괄호를 제거하거나 안쪽 문구를 일괄 정답으로 채택하는 수정은 하지 않는다.**

## 실행 순서

### 1. 작은 묶음에서 라벨을 얻을 수 있는지 먼저 확인

- 미사용 괄호 표기 후보 중 차이가 짧고 명확한 사례를 우선 고른다. 파일명·원본 JSON·
  WAV·재생 PCM을 묶고, 음성을 열기 전에 화자를 학습용과 평가용으로 분리한다.
- 첫 묶음은 주석 해석 가능성과 청취 부담을 확인할 소수만 준비한다. 새 사용자 답변을
  받기 전 파일 수를 늘리지 않는다. 기존 52개 답변은 다시 전부 요청하지 않는다.
- 전체 문장을 발음대로 새로 쓰게 하지 않고, 차이가 있는 짧은 구간과 비교 표기를
  제시해 실제로 어느 소리인지 확인한다. 두 표기 모두 가능, 둘 다 아님, 판단 어려움을
  별도로 허용한다. 잘린 구간은 원본 전체에서도 문맥과 경계를 확인할 수 있게 한다.
- 명확한 판단만 발음 라벨 후보로 남긴다. 사용자의 대략적인 자유 입력, 괄호라는
  형식, 현재 모델의 출력만으로 정확한 자모 정답을 만들지 않는다. 확인한 실제 발음에
  다시 G2P를 적용해 표준형으로 바꾸지도 않는다.
- 이번 다름 4개는 품질 검토 사례로 보존한다. 이를 새 정답 4개로 간주하지 않으며,
  일치 선택과 글자 표기가 다른 14·17번도 추가 오류로 세지 않는다.

이 단계의 산출물은 원본 전사, 확인한 발음, 판정 범위·불확실성, 원본/재생 음성 해시,
화자 분할이 있는 별도 목록이다. 기존 15만 개 라벨 전체를 검수했다고 주장하지 않는다.

### 2. 라벨만 다른 비교 학습

| 조건 | 시작 모델·음성 | 학습 정답 |
|---|---|---|
| 기준 | 기존 모델 | 추가 학습 없음 |
| 대조 학습 | 같은 기존 모델·같은 새 음성 | 기존 전사에서 만든 기대 발음 |
| 발음 라벨 학습 | 같은 기존 모델·같은 새 음성 | 청취로 확인한 실제 발음 |

두 학습의 음성 순서, 업데이트 수, 학습 레이어, 학습률, 음향 변환 조건은 같게 둔다.
라벨 외의 차이가 생기면 별도 실험으로 구분한다. 설정은 확정 자료의 길이·수량을 본 뒤
실행 전에 저장한다. 기존 직접 녹음의 진단 사례는 학습에 넣지 않는다.

라벨이 실제로 다른 학습 사례와 화자가 분리된 평가 사례가 부족하면, 같은 라벨을
비교해 놓고 효과가 없다고 판단하거나 4개만 뺀 실험으로 대체하지 않는다. 이 단계는
후보 인덱스 목록만으로 학습을 시작할 수는 없다. 이후 실제 청취 20개에서 단독 선택
10개를 얻어, 학습 6개·검증 4개의 제한된 비교를 실행했다. 실행 상태와 결과는
[라벨 비교 학습 기록](CHILD_JAMO_LABEL_COMPARISON_2026-09-27.md)을 따른다.

### 3. 정상 인식과 발음 차이 보존을 함께 평가

- 정상적으로 말한 단어를 틀리는 문제가 줄었는지 확인한다. 원래 직접 녹음의 오류는
  계속 같은 진단 기준으로 비교하되, 반복해서 본 사례만 좋아진 것을 일반화로 부르지 않는다.
- 실제로 다르게 말한 소리를 정상 단어로 바꾸는 오판을 함께 검사한다. 기존 `쌕`을
  `책`으로 출력하는 것은 개선으로 세지 않는다.
- 새 발음 평가 자료는 학습과 화자가 겹치지 않게 고정한다. 모호한 정답은 정확한
  발음 오류율 계산에서 제외하고 별도로 보고한다.
- 기존 일반 검증 성능과 정상 인식 대조군도 확인한다. 발음 라벨 조건이 전사 라벨
  조건보다 낫고 다른 발음을 숨기는 오판이 늘지 않을 때 다음 규모로 확장한다.

작은 비교가 실패하면 효과 없음의 범위와 표본·학습량 한계를 기록한다. 실패한
후보를 배포하거나, 그 결과만으로 모든 원인이 라벨이었다/아니었다고 단정하지 않는다.

## 이 계획에서 준비·완료한 것

완료: 청취 해석 72개, 원본 학습 JSON의 주석 필드 전수 검사, 미사용 괄호 표기 후보
목록, 비교 실험의 목적·대조 조건·평가 원칙, 선택형 20개 응답과 모델 대조.

첫 묶음은 **8개, 총 30.144초**, 기존 학습 화자 4명과 검증 화자 4명으로 분리했다.
독립된 단어에서 표기의 초성 또는 종성 한 부분만 다른 후보를 골랐으며, 표본·화자
분할·A/B 배치를 음성을 열기 전에 저장했다. 모델 출력은 선정에 사용하지 않았다.
이는 문자 비교 조건이며 실제 발음 오류 8개를 확정했다는 뜻이 아니다.

원본 JSON의 파일명·표기·화자·나이·시간과 WAV의 위치·길이를 대조했고, 재생 PCM은
원본 전체와 정확히 같다. 자르기·음량 변경·음높이 변경은 적용하지 않았다.
기존 학습·검증·테스트 목록 154,752개와 파일명·원본 WAV 해시·사용 PCM 해시의
정확한 중복은 없고, 새로운 학습/검증 화자도 서로 겹치지 않는다. 유사 음성 탐지까지
수행한 것은 아니다.

청취 주소: **http://127.0.0.1:8773/**. 탭 없이 8개만 확인한다. 먼저 듣고 A/B 표기를
열어 `A`, `B`, `둘 다 가능`, `둘 다 아님`, `판단하기 어려움` 중 선택한다. 자유 입력은
선택 사항이며 필수가 아니다. A/B에 전사·괄호·모델 등의 출처는 표시하지 않는다.
별도 임시 답변 DB에서 8개 재생, 모든 선택지 저장, 새로고침 복원, 답변 연결 검사와
모바일 표시를 확인했다. 실제 답변 DB에는 시험 답변을 넣지 않았다.

이 8개는 응답 완료다. 괄호 안 단독 선택 2개(`사워요`, `웡숭이`), 바깥 단독 선택
1개(`아저씨`), 둘 다 가능 3개, 둘 다 아님 2개였다. 기존 모델은 앞의 두 발음을
`싸워요`, `원숭이`로 출력했다. 3개는 사용자 선택을 보존한 조건부 라벨 후보로
기록했으며, 모호한 5개는 강제 정답으로 바꾸지 않았다.

첫 8개만으로는 라벨이 달라지는 후보가 학습용 1개·검증용 1개였다. 이후 새로운 화자의
12개를 추가 확인해 단독 선택 7개를 더 얻었다. 합계 학습 6개·검증 4개이며 이 중 라벨이
달라지는 자료는 각각 4개다. 미확정 10개는 보류했고 추가 청취 묶음은 만들지 않았다.

이를 토대로 동일 음성·동일 순서에서 라벨만 바꾸는 72회 업데이트 비교의 입력과 설정을
고정하고 실행했다. 일반 검증 1,500개와 원래 오류·정상 대조군의 평가도 완료했다.
자세한 결과와 한계는 [라벨 비교 학습 기록](CHILD_JAMO_LABEL_COMPARISON_2026-09-27.md)에
기록한다. 청취 주소 8773·8775는 완료 답변 확인용으로 유지한다.
