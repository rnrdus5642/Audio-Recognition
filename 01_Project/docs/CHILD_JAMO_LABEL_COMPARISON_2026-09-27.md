# 청취로 고른 발음 라벨과 전사 라벨의 비교 학습

이 비교 이후 전체 자모 원인 분석과 무음·음량 추가 학습 비교를 완료했다.
현재 판단과 다음 작업은 [작업 현황](CHILD_JAMO_STATUS.md)을 따른다.
이 문서의 실험 결과·고정 입력·당시 후속 권고는 보존한다.

첫 8개와 추가 12개를 합친 **20개 중 10개에서 단독 선택을 얻었다.** 학습 화자의
6개와 다른 검증 화자의 4개이며, 전사와 라벨이 달라지는 사례는 각각 4개다.
이 자료로 두 조건의 72회 업데이트와 평가를 완료했다. **이번 후보는 채택하지 않는다.**
청취 라벨 조건은 학습 음성 일부에서 나아졌지만, 다른 화자와 원래 오류는 개선하지
못했고 `쌕`을 `책`으로 바꾸는 오판이 생겼다. 원래 모델을 유지한다.

## 청취 분석

| 사용자 판단 | 첫 8개 | 추가 12개 | 합계 |
|---|---:|---:|---:|
| 괄호 안 표기로만 들림 | 2 | 6 | 8 |
| 괄호 밖 표기로만 들림 | 1 | 1 | 2 |
| 둘 다 가능 | 3 | 3 | 6 |
| 둘 다 아님 | 2 | 1 | 3 |
| 판단 어려움 | 0 | 1 | 1 |

추가 12개에서 선택한 내용과 기존 모델의 출력은 다음과 같다. 표기 선택은 한 사람의
단어 청취 판단이며, 전문가 음성 전사로 취급하지 않는다.

| 추가 문항 | 미리 정한 용도 | 사용자 선택 | 기존 모델 출력 |
|---|---|---|---|
| 3 | 검증 | 춤서요 | 춤춰요 |
| 4 | 검증 | 쿠레용 | 포레용 |
| 5 | 학습 | 사탕 | 사탕 |
| 8 | 학습 | 누구이까요 | 누구일까요 |
| 9 | 학습 | 아저씨 | 아저씨 |
| 10 | 학습 | 웡충이 | 원숭이 |
| 12 | 검증 | 운등화 | 운동화 |

추가 1번은 둘 다 아님, 2·7·11번은 둘 다 가능, 6번은 판단 어려움이다. 이 다섯
문항에 정답을 추측해 붙이지 않았다. 첫 묶음의 미확정 다섯 문항도 동일하게 보류한다.
모든 자유 입력은 빈 문자열이며, 선택하지 않은 발음을 모델 출력에서 가져오지 않는다.

20개 중 단독 선택 10개에서 기준 모델은 3개가 정확히 일치했다. 나머지 7개 중 6개는
사용자가 고른 괄호 안 발음 대신 바깥 표기를 출력했고, 1개는 두 표기와 모두 달랐다.
작은 괄호 표본이므로 전체 데이터의 오류율로 해석하지 않는다.

## 이번에 검증하는 가설과 범위

원본 전체 PCM에서도 위 차이가 나타났으므로 이번 사례를 우리 자르기·음향 변환으로
설명하지 않는다. 원본 JSON과 재생 WAV, PCM 해시, A/B 역할, 답변 revision을 재검증했다.
20개 모두 기존 학습·검증·테스트 목록에 없었다. 기존 학습에 이 20개를 잘못 넣었다는
설명도 해당하지 않는다.

이 실험은 **같은 음성에서 전사 라벨 대신 선택한 실제 발음 표기를 학습하면, 다른
화자의 발음 차이 보존이 나아지는지** 확인한다. 기존 모델이 원래 오류를 얻은 과정을
재현한 인과 증명이 아니다. `사랑(사탕)`의 경우 발음 변화인지 다른 단어를 읽은 것인지도
따로 판정하지 않으며, 들린 말 선택만 감독 정보로 사용한다.

## 고정한 실행 조건

- 기준 모델: 기존 `main/best.pt`. 두 조건 모두 같은 원본 가중치에서 새로 시작한다.
- 전사 조건: 학습 후보 6개에 바깥 전사에서 만든 발음 라벨을 사용한다.
- 청취 조건: 같은 6개에 사용자가 단독 선택한 표기를 사용한다. 다시 G2P로 바꾸지 않는다.
- 두 조건에서 라벨이 실제로 다른 파일은 4개다. `아저씨` 2개는 같은 라벨을 유지한다.
- 각 72회 업데이트. 매번 검수 음성 1개와 기존 수정 학습 목록의 음성 3개를 사용한다.
  검수 음성 6개는 각각 12번, 기존 음성 216개는 각각 1번 노출된다. 총 288개 노출이다.
- 학습 음성 순서·무작위 시드·학습률·마지막 8개 Transformer 층과 CTC 출력층은 같다.
  인코더 학습률 `1e-5`, 출력층 `5e-5`, AdamW, 기울기 상한 1.0을 사용한다.
- 음높이·속도·자르기·SpecAugment를 추가하지 않는다. 기본 학습 dropout은 같은 시드로
  적용하며, 두 조건의 매 업데이트 난수 상태까지 비교한다.
- 모호한 답변·개인 진단 녹음·새 검증 화자의 음성은 학습에서 제외한다. 기존 청취 사례도
  216개 보충 학습 음성에서 제외했다. 원래 학습 목록은 수정하지 않는다.
- 최종 72번째 가중치만 평가한다. 검증 결과에 맞춰 반복 조정하거나 가장 좋은 중간
  체크포인트를 선택하지 않는다.

## 평가와 판단 기준

학습 6개에서의 일치는 학습 적합 정도다. 일반화 근거와 구분해 기록한다. 검증은 다른
화자의 4개, 기존 일반 검증 1,500개, 기존 개인 진단 13개(단독 판단 11개), 사람이
확인했던 학습 음성 6개를 사용한다. 별도 테스트 2,999개는 새로 평가하지 않는다.

다음 규모로 확대할 만한 결과는 청취 라벨 조건이 기준 모델과 전사 조건보다 새 검증
4개의 자모 오류와 바깥 표기로의 치환을 줄이고, 정확한 일치를 추가하며, 기존 검증
자모 오류율 증가가 절대 0.001 이내이고 기존 정상 진단의 퇴행이 없는 경우다.
`쌕`을 `책`으로 바꾼 결과는 개선으로 세지 않는다.

표본은 학습 6개·검증 4개이고 한 시드뿐이다. 위 조건을 통과해도 원래 오류 해결이나
넓은 일반화 성능을 확정하지 않으며, 모델을 자동으로 교체하지 않는다. 통과하지 못하면
이 후보를 확대·배포하지 않고 한계와 다음 작업을 결정한다.

## 완료 결과

| 평가 | 기존 모델 | 전사 라벨 학습 | 청취 라벨 학습 |
|---|---:|---:|---:|
| 학습 6개에서 청취 선택과 정확 일치 | 3/6 | 3/6 | 4/6 |
| 학습 6개 자모 오류 | 4/41 | 4/41 | 2/41 |
| 다른 화자 4개에서 정확 일치 | 0/4 | 0/4 | 0/4 |
| 다른 화자 4개 자모 오류 | 6/30 | 6/30 | 6/30 |
| 일반 검증 1,500개 자모 오류율 | 2.9504% | 3.0016% | 3.0529% |
| 기존 개인 진단의 청취 선택과 정확 일치 | 2/11 | 2/11 | 2/11 |
| 사람이 `쌕`으로 고른 음성의 출력 | `ㅐㄱ` | `색` | `책` |

청취 라벨 조건에서 `누구일까요` 출력은 선택한 `누구이까요`로 바뀌었다.
`원숭이`는 `웡숭이`로 바뀌었지만 선택한 `웡충이`와는 여전히 다르다.
`사워요`도 계속 `싸워요`로 출력한다. 따라서 학습 6개를 모두 맞힌 결과가 아니다.

새 검증 출력은 세 모델에서 모두 같다: `춤서요→춤춰요`, `운등화→운동화`,
`쿠레용→포레용`, `웡숭이→원숭이`. 기존 진단의 `책→샙`,
`뛰어가요→귀어 가요`도 그대로다. `나비→나리`는 두 학습 조건에서 `날비`가 되어
여전히 틀렸다. 정답이 모호했던 다른 `책` 음성의 출력 변경은 개선으로 세지 않았다.

청취 조건의 일반 검증 오류는 979개에서 1,013개로 늘었다. 오류율 증가는 약
0.1025%p로 사전에 정한 0.1%p 한계를 조금 넘었다. 증가 폭만으로 판단한 것이 아니라,
다른 화자의 개선 부재와 `쌕→책` 오판을 함께 근거로 후보 채택과 확대를 중단한다.
기존에 맞던 정상 진단은 유지됐지만, 이것만으로 발음 차이가 보존된다고 볼 수 없다.

두 조건의 음성 순서·노출 수·설정·매 업데이트 난수 상태가 일치했다. 저장된 최종
모델을 다시 읽어 청취 사례의 출력 20개(조건별 10개)가 평가 기록과 같음도 확인했다.
추가 최적화나 체크포인트 선택은 하지 않았다. 원래 모델과 학습 목록은 보존했다.

## 무엇을 알았고 무엇이 아직 남았나

라벨 변경은 모델에 반영됐다. `사워요`의 선택 라벨에 대한 CTC 손실은 기존 7.853에서
청취 조건 1.716으로, `웡충이`는 23.447에서 4.053으로 줄었다. 다만 청취 조건에서도
바깥 표기 `싸워요`, `원숭이`의 손실은 각각 0.199, 0.924로 더 낮다. 이는 정답의
진실 확률이 아니라 모델이 각 문자열에 부여하는 적합도다. 라벨 전달 실패의 근거는
없지만, 이번 학습량과 혼합 조건에서 두 사례를 충분히 학습하지 못했다.

표본의 대조 범위도 좁았다. 검증 4개의 모든 글자 차이를 이번 학습 6개에서 다룬
사례는 `원숭이/웡숭이` 하나뿐이다. `춤춰요/춤서요`의 모음 차이, `운동화/운등화`,
`크레용/쿠레용`의 모음 차이는 새 학습 라벨 쌍에 없었다. 이는 한글 초·중·종성의
표기 비교이며 전문 음소 판정이 아니다. 기존 대규모 학습이나 216개 보충 음성에서
해당 소리를 배운 적이 없다는 뜻도 아니다.

원래 오류와 관련된 `ㅂ/ㄹ`, `ㄸ/ㄱ`, 종성 `ㄱ/ㅂ` 대조도 이번 학습 6개의 라벨
차이에 없었다. 기존에 추출해 둔 짧은 괄호 단어 후보 안에서는 `ㅂ/ㄹ`, `ㄸ/ㄱ`을
찾지 못했고 종성 `ㄱ/ㅂ`은 학습 후보 2개·검증 후보 0개였다. 이 제한된 후보 목록의
숫자를 전체 데이터셋의 부재나 확인된 발음 오류 수로 해석하지 않는다.

**따라서 라벨 가설을 입증하거나 배제하지 못했다.** 원래 오류의 원인을 확정한
것도 아니다. 확인된 것은 이번 소규모 라벨 개입의 부분적인 학습 효과와 개선 실패다.

## 당시 후속 권고와 완료 상태

아래 적합도 후속 비교 학습은 실행하지 않았다. 이 비교가 끝났을 때의 권고는
이미 청취한 6개로 **선택 라벨만 학습하는 조건과 기존 음성을 함께 학습하는 조건의
적합도**를 비교하는 것이었다. 청취 음성 노출 수와 학습률을
고정하고, 학습 6개의 오류·선택 라벨 손실·정상 대조군을 함께 기록하면 이번의 부족한
학습량과 기존 음성 혼합의 영향을 구분하는 데 도움이 된다. 이는 적합도 진단이며,
6개를 외우거나 원래 진단을 반복해서 맞히는 것을 일반화 개선으로 간주하지 않는다.

그 결과를 바탕으로 원래 문제의 자음 대조가 학습과 다른 화자의 평가 양쪽에 포함되도록
자료를 설계한다. 임의의 괄호 단어를 더 듣게 하거나 현재 후보로 대규모 재학습을
반복하는 것은 권하지 않는다. 새 청취가 꼭 필요한 항목을 특정한 뒤에만 요청한다.

현재까지 사람 청취 72개는 모두 응답 완료이고, 추가 청취 요청과 실행 중인 학습은 없다.
위 후속 실험은 권고이며 아직 시작하지 않았다. 원래 오류는 미해결 상태다.
