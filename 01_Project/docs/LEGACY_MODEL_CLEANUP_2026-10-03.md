## 현재 실행과 재현 범위

`05_Run`에는 자모 마이크와 청취 페이지 세 종류의 실행·열기 항목을 둔다.
기존 7860 서버는 종료하고 기존 실시간 인식 실행 항목을 제거했다.
구형 Unity 추론은 ONNX와 검증 빌드를 제거한 상태이므로, 필요하면 보존한 아동 최종본에서
ONNX를 다시 내보내고 Unity에서 임포트·검증해야 한다. Unity 소스와 패키지 이력은 남겼다.
공개 음절 후보를 다시 전부 비교하려면 삭제한 후보 가중치의 재다운로드도 필요하다.
삭제한 중간 옵티마이저 상태로 과거 학습을 재개할 수는 없다.

현재 HuBERT 본학습·추가 실험, 기반 인코더, 자모·음소 후보, 데이터셋 원본·추출 음성,
녹음·답변·학습 목록은 보존했다. 특히 이전 `child_finetune/data/dev.csv`는 현재 자모 학습의
분할 검사에 필요하므로 유지했다. 사용자 계정의 공용 모델 캐시와 별도 프로젝트는 이번 삭제 범위가 아니다.
