# 전체 자음·모음의 오류와 원인 분석

이 문서는 2026-09-27 원인 분석 기록이다. 이후 추가 학습과 마이크 테스트를 포함한
현재 판단은 [작업 현황·문서 안내](CHILD_JAMO_STATUS.md)를 따른다.

**모델 내부의 문맥 민감성을 통제 실험으로 확인했고, 실제 발음 보존과 전사 복원이
섞인 학습·평가 구조를 확인했다.** 특정 단어 세 개의 문제로 범위를 제한할 수 없다.
다만 모든 인식 오류를 하나의 원인으로 설명하거나, 각 원인의 전체 기여율을 확정한
결과는 아니다. 새 재학습·모델 교체·사용자 청취 요청은 하지 않았다.

## 무엇을 새로 검사했나

- 기존 검증 **1,500개·224명·33,182자모**의 개별 예측을 전부 집계했다. 출력 40개
  자모 각각의 분모, 대치·탈락·삽입, 참조 표기의 초성·중성·종성을 기록했다.
- 원래 학습 **150,253개**의 자모 출현량을 세고, 검증 화자·길이·단어/문장·어휘
  노출에 따른 차이를 계산했다. 이 출현량과 오류의 관련성 자체를 인과 증거로 보지 않는다.
- 이전 청취에서 단독 판단이 있는 **27개**에 원래 모델을 적용했다. 개인 녹음 11개,
  청취로 확인했던 기존 학습 음성 6개, 추가 선택형 청취의 학습 후보 6개·검증 후보 4개다.
- 27개에서 반복 실행, 학습용 여백 마스크, 0.5초 무음 추가, 12dB 감쇠, 인코더 내부
  위치·attention 경로의 2×2 조작을 검사했다. 오답에는 폭 50의 빔 탐색도 대조했다.
- 검증 1,500개를 이전의 원본/학습 PCM 전수 감사에 연결했다. 원본 전체인지 잘린
  구간인지, 표시 과정에서 자모가 없어졌는지, 라벨 재계산이 일치하는지도 검사했다.

개인 녹음과 선택형 답변은 사용자가 들은 단어 표기 기준이다. 정밀 음소 전사나
무작위 성능 표본으로 취급하지 않는다. 모호한 답변과 대략적인 자유 입력은 정확도
계산에 새 정답으로 넣지 않았다.

## 인코더 내부까지 추적한 결과

무음을 앞뒤에 추가한 입력에서 원래 말소리 부분의 convolution 특징을 원래 입력의
특징과 정확히 같게 복사했다. 이어 주변 무음의 위치 신호와 attention 접근 여부만
독립적으로 바꾸었다. 원래 말소리 프레임의 출력만 읽었다. 두 경로를 모두 가린
대조 조건은 **27개 모두 원래 출력과 같았다.**

| 청취 선택 | 원래 출력 | 말소리 특징을 고정한 내부 조건 | 출력 |
|---|---|---|---|
| 나비 | 나리 | 주변 무음에 대한 attention 접근만 허용 | 나비 |
| 뛰어가요 | 귀어 가요 | 주변 무음의 위치 신호만 허용 | 뛰어가요 |
| 가요 | 봐요 | 주변 무음의 위치 신호만 허용 | 가요 |
| 가 | 하 | 주변 무음에 대한 attention 접근만 허용 | 카 |
| 실로폰 | 켈리폰 | 주변 무음의 위치 신호만 허용 | 킬로폰 |
| 놔요 | 와요 | 주변 무음의 위치 신호만 허용 | 봥 |
| 놔 | 봐 | 주변 무음의 위치 신호만 허용 | 바 |
| 쌕 | ㅐㄱ | 주변 무음에 대한 attention 접근만 허용 | 책 |

개인 오류 9개 모두 적어도 한 내부 조건에서 출력이 달라졌으며, 그중 청취 선택과
일치한 조건이 있는 것은 3개다. attention만 바꾸면 전체 27개 중 5개, 위치 신호만
바꾸면 10개가 달라졌다. 두 조작의 영향은 단순히 더해지지 않는다.

실제 파형에 무음 0.5초씩을 덧붙인 검사에서는 4/27, 음량을 12dB 낮춘 검사에서는
3/27의 출력이 바뀌었다. 이것은 입력 조건에 따른 민감성을 실제 입력 경로에서도
확인한 결과다. 내부 조작은 진단용이며 실제 서비스 정책이 아니다. `쌕→책` 같은
위험한 치환과 정상 음성의 퇴행도 생기므로 무음 추가나 감쇠를 해결책으로 적용하지 않는다.

따라서 `책`, `가`, `놔` 등의 잘못된 자모는 표시기가 만든 것이 아니라 모델이 이미
출력한 것이다. 그중 일부는 말소리 내용 외의 문맥 신호에 따라 자모 선택이 바뀌는
과정을 거친다. 어떤 사전학습/추가학습 자료가 이 민감성을 만들었는지는 아직 분리되지 않았다.

## 표준형으로 바꾸는 오류는 다른 양상이다

`사워요→싸워요`, `웡충이→원숭이`, `누구이까요→누구일까요`,
`춤서요→춤춰요`, `운등화→운동화`, `웡숭이→원숭이`는 이번 음량·무음·내부 문맥
조건과 빔 탐색에서 모두 유지됐다. 현재 모델은 청취 선택보다 이 전사형 문자열에
더 높은 CTC 점수를 부여했다. 이 점수는 모델의 문자열 선호이며 사람이 정확하게
발음했을 확률이 아니다.

학습 정답은 `LabelText → 프로젝트 G2P → 자모`이고 실제 소리를 독립적으로 기록한
정답이 아니다. 앞서 청취한 기존 학습 18개 중 불일치 3개는 원본 전체 음성과 전사에서
이미 차이가 있어 우리 자르기나 G2P 문자 변경으로 설명할 수 없었다. 또 괄호 표기
자료는 해석하지 않고 제외하며, 제공 오류 주석은 선택된 학습 자료에서 사용 가능한
내용이 없었다. 실제 발음 차이를 배우기 위한 정보가 충분히 감독되지 않는 구조다.

동일 음성·동일 설정에서 라벨만 바꾼 이전 실험은 학습 6개의 오류를 4자모에서
2자모로 줄였지만 다른 화자 4개에서는 6자모 오류가 그대로였다. 이는 라벨 개입이
학습 출력에 영향을 준 증거지만, 현재 문제의 원인이 전부 라벨이라는 증거나
새 화자에서도 해결되는 방법을 확보했다는 뜻은 아니다.

## 전체 자모 결과와 평가 기준의 한계

검증 1,500개에서 **978개 편집 차이**가 있었다. 자음은 대치 309·탈락 180·삽입 86,
모음은 대치 260·탈락 95·삽입 48이다. 참조 표기의 자음 19종·모음 21종 모두 적어도
한 번 대치 또는 탈락이 있었다. 희소 자모는 사례 수가 적어 비율을 일반화하지 않는다.

| 참조 표기의 위치 | 출현 수 | 대치 | 탈락 |
|---|---:|---:|---:|
| 초성 | 14,672 | 254 | 110 |
| 중성 | 14,672 | 260 | 95 |
| 종성 | 3,838 | 55 | 70 |

삽입은 대응하는 참조 자모가 없어 이 표의 위치에 임의 배정하지 않았다. 이 결과는
문자열 최소 편집 정렬이며 음향 정렬이 아니다. 특히 `ㅇ`은 초성의 무음 표기와
종성의 비음을 함께 쓰므로 합산 수치를 하나의 음소 오류율로 부르지 않는다.

모음 `ㅢ`는 67회 중 대치 11회, `ㅚ`는 55회 중 대치·탈락 7회였다. 여기서
`외국의→외구게`, `전설의→전서레`, `속의→소게`, `남들의→남드레`의 `ㅔ` 위치도
차이로 계산된다. 국립국어원은 조사 `의`를 `[에]`로 발음하는 것도 허용한다고
설명한다. 따라서 단일 전사 기반 정답과 다른 것만으로 실제 발음을 잘못 인식했다고
판정할 수 없다. 이 4개 음성의 실제 소리나 문장 전체의 정오를 새로 확정한 것은 아니다.
[국립국어원: 표준 발음법 제5항 설명](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=98&pageIndex=1&qna_seq=324254)

위 네 문맥만 허용 대안으로 비교하면 편집 차이는 각각 1개씩 줄지만, 기존 정답·
모델·공식 성적은 수정하지 않았다. 모든 `ㅢ/ㅔ`를 합치거나 비표준 발음을 정상화하는
규칙을 넣지도 않았다. 실제 발음 전사 평가와 허용 발음 판정은 목적을 구분해야 한다.

## 원본과 전처리, 사용 조건을 구분한 근거

검증 728개는 원본 전체 음성을 그대로 사용했고 여기서 차이 584개가 발생했다.
나머지 잘린 구간 772개에서 차이 394개가 발생했다. 원본 전체를 사용한 584개 차이는
우리 자르기가 말소리를 누락시킨 것으로 설명할 수 없다. 그렇다고 원본 전사와
실제 소리가 모두 맞다고 확인된 것은 아니다.

검증에서 차이가 가장 많던 한 화자는 13개 중 12개가 전사와 달랐고, 전체 차이의
118/978(12.1%)를 차지했다. 13개 모두 원본 전체였다. 표본의 화자·녹음·발음·라벨
조건을 분리하지 않고 특정 자음이 전체 아동에게 약하다고 해석해서는 안 된다.

학습 자료의 1.5초 미만 파일은 37개(0.0246%)이고, 검증에는 1개뿐이다. 직접 녹음은
83개 중 74개가 1.5초 미만이다. 파일 길이는 실제 말소리 길이와 같지 않다. 이전
대조에서는 다른 화자의 `책` 22개가 여백을 줄여도 모두 라벨과 일치했고, 이번 전체
검증의 단독 단어 87개도 85개가 일치했다. 따라서 단독 단어 또는 짧은 길이 자체를
단일 원인으로 삼을 수 없다. **실제 사용할 짧은 발화·주변 문맥·비표준 발음 조건이
기존 평균 점수에서 충분히 검증되지 않았다는 점**이 문제다.

## 이 분석 직후의 권고

아래 권고 중 무음·음량 비교 학습은 이후 완료했다. 결과는 이 문서 마지막 절과
[추가 학습 판정](CHILD_JAMO_CONTEXT_CONCLUSION_2026-09-27.md)에 있다.

1. 평가를 실제 발음 전사, 전사형 복원, 허용 발음 판정으로 구분한다. 현재의 전사
   일치 점수만으로 발음 보존 성능이나 개선 여부를 판단하는 것을 중단한다. 기존
   청취 판단과 모호함을 보존하고, 확인하지 않은 라벨은 음소 정답으로 승격하지 않는다.
2. 다음 모델 개입은 **말소리를 보존한 여백·음량 변화에 대한 출력 일관성**과
   **표준형으로 바꾸지 않는 발음 감독**을 각각 검증하도록 설계한다. 앞선 음높이·
   속도 실험이나 실패한 6개 라벨 학습을 그대로 확대하는 방식은 근거가 부족하다.
3. 초성·종성·모음 전체, 정상 발음과 다른 발음, 학습과 다른 화자를 포함한 고정
   평가에서 판단한다. 추가 청취가 필요하면 특정 원인 판정을 바꿀 수 있는 사례만
   선정한다. 이번 분석에서는 추가 청취나 학습을 시작하지 않았다.

인식 오류를 고쳤다는 보고는 아니다. **왜 이전 점수와 소규모 재학습으로 원인을
판별하기 어려웠는지, 오류가 어느 계산 단계와 감독 구조에 걸쳐 있는지를 좁힌 결과다.**
