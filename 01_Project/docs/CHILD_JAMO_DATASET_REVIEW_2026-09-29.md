이를 전처리에서 말소리를 잘라낸 문제 하나로 설명할 수 없다.
추가 학습이나 자동 라벨 수정을 실행하지 않았다.

하지만 학습 정답은 `고양이가 조라요`라서, 기존 전사 기반 평가에서는 차이로 센다.
이 사례는 **전사 일치 점수와 실제 발음 보존을 구분해야 한다**는 근거다.

## 어느 단계에서 생긴 차이인가

선정 시 보관한 원본 JSON·학습 행·재생 파일·모델 출력·답변 binding을 다시 대조했다.
20개의 원본 전사 정규화·G2P 표기·토큰 ID가 기존 학습 기록과 같고,
웹의 학습 PCM도 원본의 정확한 구간과 같다. 파일 연결이나 변환 재현의 불일치는 없다.
동일 코드를 재실행한 확인이므로 G2P의 언어학적 적합성까지 입증하는 검사는 아니다.

| 번호 | 원음·학습 구간 비교 | 원인에 관해 말할 수 있는 범위 |
|---|---|---|
| 3 | 앞 0.500초 제외. 제외된 8,000개 샘플은 모두 정확히 0 | 원본 전사와 G2P가 같다. 말소리 신호를 잘라내거나 G2P에서 글자를 바꿔 생긴 차이로 설명할 수 없는 원본 음성-전사 쌍의 불일치 보고 |
| 4 | 원본 전체 PCM 그대로 | 자르기로 말소리가 없어진 경우는 아님. 원본 전사와 G2P 중 어느 표기가 실제 소리와 어긋나는지는 정밀 청취로 분리해야 함 |
| 6 | 원본 전체 PCM 그대로 | 자르기로 ㄹ 소리가 없어진 것으로 설명할 수 없음. 현재 정답과 청취·모델의 방향이 다른 평가 사례 |
| 10 | 앞 1.270초 제외. 이후 원본 청취에서 `문제가 된 소리는 원본에서도 같음` 선택 | 전사와 G2P 모두 `장미가 예뻐요`. 보고한 차이가 자르기 전 원본에도 있으므로 자르기로 처음 생긴 차이라는 설명은 지지되지 않음. 제외 신호의 종류와 경계의 완전한 적합성은 이 답만으로 확정하지 않음 |
| 15 | 앞 0.310초 제외. 제외된 4,960개 샘플은 모두 정확히 0 | 말소리 신호의 삭제로 설명할 수 없음. G2P에서 표기가 바뀌므로 원본 전사와 규칙의 기여는 별도 확인 필요 |

따라서 **5개 중 4개(3·4·6·15)는 학습 구간을 만들면서 0이 아닌 말소리 신호를 삭제하지 않았다.**
이는 모든 자르기가 올바르다는 결론이나, 무음 길이 변화가 모델 문맥 처리에 영향을 주지 않는다는
결론이 아니다. 특히 10번의 큰 신호가 반드시 해당 아동의 발화라는 해석도 하지 않는다.

10번은 물리적으로 0이 아닌 신호를 제외한 사실을 그대로 남긴다. 추가 청취는 이 신호의
정체를 판정한 답이 아니라, **문제가 된 소리가 원본에서도 같았다**는 답이다.
따라서 원본 음성-전사 쌍의 불일치 보고로 분류하되, 자르기가 모델 출력에 미친 영향까지
모두 배제했다고 해석하지 않는다. 3·10번은 G2P의 문구 변경 없이도 보고된 차이가 존재한다.

공급자의 STT 전사 지침상 잘못된 라벨인지와, 이 전사를 실제 발음 그대로의 정답으로
써도 되는지는 다른 질문이다. 현재 근거가 직접 가리키는 것은 후자의 적합성 문제다.
이를 실제 발음에 맞추지 않은 채 전사→규칙 변환 결과만 감독 정보로 쓰는 설계의 한계가 남는다.

## 첫 인상과 최종 선택을 함께 보존한 항목

- 2번: 첫 메모는 `뱃소리가 들려요`, 최종 선택은 `벨소리가 들려요`와 일치.
  최종 선택을 다름으로 뒤집거나 메모를 확정 전사로 채택하지 않았다.
- 8번: `어린삭`이라고 적었지만 `어린싹` 쪽을 선택했다. 문항의 초점은 ㄹ 초성의 유무였으므로
  이 답만으로 ㅅ/ㅆ까지 판정하지 않는다.
- 9번: `자끈언니`라고 적었지만 `자그넌니` 쪽을 선택했다. 비교의 초점은 ㅜ/ㅡ였다.
  따라서 모음 선택을 ㄱ/ㄲ가 정확하다는 판단으로 확대하지 않는다.

이 세 항목은 추가 오류 수에 넣지 않았고, 정밀 발음 정답으로도 인증하지 않았다.
사용자가 앞서 밝힌 “메모가 발음 그대로의 글자는 아닐 수 있다”는 조건을 유지한다.

확인한 것은 아니다.

## 권고와 완료 상태

**다음 우선순위는 실제 발음 기준으로 평가할 자료를 먼저 확정하는 것이다.**
이번 5개는 이미 본학습에 사용한 진단 자료이므로 새 화자
성능 검증 자료로 사용하지 않는다.

1. 이번 불일치 5개를 라벨 검토 후보로 보존한다. 정밀 확인 전까지 메모로 자동 재라벨하거나
   학습 목록에서 자동 삭제하지 않는다.
2. **10번의 원본 비교는 완료했다.** 사용자는 원본에서도 같은 소리라고 답했다.
   새 청취 묶음을 만들거나 같은 질문을 반복 요청하지 않는다. 기존 20개 답변과 첫 인상,
   revision 20·21의 이력을 모두 보존한다.
3. 실제 소리를 확인한 정상·변이 발음 대조를 준비하고, 같은 대조가 학습군과 다른 화자의
   평가군 모두에 포함되도록 고정한다. 기존 모델이 보지 않은 화자를 최종 평가에 사용한다.
   이후 라벨만 달리하는 동일 조건의 비교 학습으로 효과를 확인한다.

앞선 [6개 학습·4개 검증의 라벨 비교](CHILD_JAMO_LABEL_COMPARISON_2026-09-27.md)는
학습 예제 일부만 개선했고 새 화자에서는 개선하지 못했다. 학습·평가 간 발음 대조의
범위도 충분히 겹치지 않았다. 같은 소량 실험을 그대로 반복하거나 현재 라벨로 학습량을
늘리기 전에 위 평가 조건을 먼저 갖추도록 권고한다.

정답 확정 시에는 원본 전사, 학습용 G2P 표기, 실제 청취 표기를 서로 다른 필드로 둔다.
청취 표기는 실제 소리를 확인한 범위만 기록하고, 모호한 구간은 보류한다.
메모나 모델 출력을 발음 정답으로 자동 채택하지 않는다. 비교 학습 전에는 평가 자료와
화자를 고정하고, 원래 전사 표기로의 치환과 실제 발음 보존을 각각 측정한다.
