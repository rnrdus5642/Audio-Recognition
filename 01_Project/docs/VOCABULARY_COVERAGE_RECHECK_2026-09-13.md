# 현재 모델의 누락 음절 재점검 — 2026-09-13

현재 아동 모델과 전사 색인을 다시 대조했다. **기존 5~7세 화자 분할 범위에서는
523종, 전체 전사 색인에서는 826종의 한글 음절이 모델 출력 목록에 없다.**
현재 모델·배포 글자표·원본 전사·학습 분할·Unity 코드는 변경하지 않았다.

## 모델과 조사 범위

- 모델: `python/tools/child_finetune/runs/child/best`
- 출력: 한글 음절 **1,202개**와 특수 항목 3개, 총 **1,205개**.
- 체크포인트의 모든 출력 토큰과 번호가 현재 Unity 배포 어휘와 일치한다.
- 전체 색인 2,765,817행을 읽고, 현재 학습 코드의 NFC 정규화 후 한글 음절을 집계했다.
- 길이·실제 WAV 존재 여부·화자별 표본 제한을 적용하기 전의 **전사 행** 기준이다.
  전체 색인에 해당하는 모든 WAV가 추출되어 있거나 학습에 사용됐다는 뜻은 아니다.

| 범위 | 전사 행 | 실제 등장 음절 종류 | 그중 출력 목록에 없는 음절 | 누락 음절을 포함한 전사 행 |
|---|---:|---:|---:|---:|
| 기존 5~7세 화자 분할에 배정된 범위 | 654,677 | 1,694 | **523** | **50,753 (7.75%)** |
| 전체 전사 색인 | 2,765,817 | 2,023 | **826** | **276,422 (9.99%)** |

523과 826의 차이는 조사 범위 차이다. 모델이 바뀌어서 누락이 늘어난 것이 아니다.
모델의 글자표·설정, 색인, 화자 분할의 SHA-256이 9월 6일 기록과 모두 일치했고,
기존 범위의 누락 수와 분할별 집계도 같았다.

음절 **종류 수**는 사용 빈도와 다르다. 기존 범위에서 전체 7,206,049회 음절 출현 중
누락 음절은 61,915회(0.86%)였다. 한 문장에 누락 글자 하나만 있어도 해당 전사를
영향 행으로 세므로, 위의 7.75%와 다른 지표다. 어느 값도 실제 음성 인식 오류율이나
게임의 정답 실패율을 측정한 결과는 아니다.

## 일상 단어에도 포함되는 누락 글자

아래는 현재 어휘로 철자를 그대로 만들 수 없는 예다. 예시 단어가 기존 범위의
실제 전사에 포함된 것도 확인했다. 표의 횟수는 음절 하나의 출현 횟수이며 단어 횟수가 아니다.

| 누락 음절 | 예시 단어 | 기존 범위에서 해당 음절의 출현 횟수 |
|---|---|---:|
| 깜 | 깜짝 | 2,049 |
| 얀 | 하얀 | 1,984 |
| 뚱 | 뚱뚱 | 1,782 |
| 괜 | 괜찮아 | 1,060 |
| 펭 / 귄 | 펭귄 | 813 / 854 |

`놔`도 빠져 있다. `잡아`의 `잡`과 `아`는 모두 있으므로, 이 단어의 음성 인식 문제는
출력 글자 누락으로 설명되지 않는다. 현재 배포 정답 29개를 따로 점검하면 누락 글자는
`놔` 하나이고, `놔`·`놔요` 두 정답이 영향을 받는다.

## 학습 데이터에 미치는 영향

현재 `manifest.load()`는 전사에 어휘 밖 글자가 하나라도 있으면 그 발화를
학습 후보에서 제외한다. 길이 필터보다 먼저 적용된다.

| 기존 분할 | 전사 행 | 누락 음절 종류 | 누락 글자를 포함한 전사 행 |
|---|---:|---:|---:|
| train | 407,068 | 467 | 31,485 |
| dev — train 화자에서 분리 | 22,366 | 268 | 1,885 |
| valid | 111,791 | 371 | 8,712 |
| test | 113,452 | 339 | 8,671 |

현재 저장된 학습용 `train.csv` 123,943행과 `dev.csv` 787행도 다시 읽었다.
두 파일 모두 누락 글자가 든 전사는 0행이었다. 따라서 기존 학습 목록을 그대로
재학습하는 것만으로 누락 글자의 전사 예시가 학습에 추가되지는 않는다.
valid/test는 이번에 통계 확인에만 사용했다.

## 작업 범위에 대한 판단

‘놔’ 보완은 제한된 정답 목록에 대한 대응이다. 여러 콘텐츠의 일상 단어를 폭넓게
지원하려면 **출력 어휘와 학습 데이터 선정 방식도 함께 검토할 필요가 있다.**
필요한 음절을 묶어 확장·학습하는 방법과 자모 출력으로 전환하는 방법이 후보이며,
이 집계만으로 어느 쪽의 인식 성능이 더 좋을지는 판단하지 않았다.

누락 826종을 모두 반드시 추가해야 한다는 의미도 아니다. 서비스 대상 단어,
학습 분할의 빈도, 전사 품질을 기준으로 결정해야 한다. 이전 기록의 단독 IPA 동치
110종·413종·391가지 분석은 이번에 재실행하지 않았다.
