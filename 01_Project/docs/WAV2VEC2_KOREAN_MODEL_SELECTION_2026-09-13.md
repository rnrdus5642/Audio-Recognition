**한국어 자모·음소 모델 선정: 64개 체크포인트 실측 — 2026-09-13 시작 실험**

**현재 목적에서는 Miniijune V2를 아동 파인튜닝의 우선 후보로 추천한다. 앞서 SLPLab만 먼저 시험하고 우선 추천했던 판단은 수정한다.** 성인 문장과 보유 악기놀이 단어를 함께 보면 Miniijune V2의 출발 성능이 더 좋았다. 다만 현재 제품 모델의 즉시 교체를 확정하는 결과는 아니다. 앞으로 우리 아동 자료를 같은 조건으로 학습한 뒤 최종 교체를 결정해야 한다.

우선 후보는 [Miniijune/wav2vec2-xls-r-300m-Korean-children-pronunciation-jamo-based-V2](https://huggingface.co/Miniijune/wav2vec2-xls-r-300m-Korean-children-pronunciation-jamo-based-V2)다. 기존 원본 대비 성인 문장의 기준 소리 오류율이 **18.6% → 8.5%**, 사용자 성인 단어의 소리열 완전 일치가 **2/7 → 7/7**, 악기놀이 녹음은 **3/46 → 31/46**로 개선됐다. ‘놔’를 글자 하나로 갖고 있어야 하는 음절 방식의 제약도 피할 수 있다. 그렇다고 ‘놔’를 항상 정확히 듣거나 아동의 발음 오류를 정확히 지적한다는 뜻은 아니다.

[student-47 V5](https://huggingface.co/student-47/wav2vec2-large-xlrs-korean-v5)는 일반 문장 자모 ASR 비교군으로, [SLPLab 한국어 음소](https://huggingface.co/slplab/wav2vec2-xls-r-300m_phone-mfa_korean)는 명시된 음소 체계와 학습 설명을 가진 비교군으로 남기는 것이 좋다. Miniijune semi V2는 같은 계열의 예비 후보이며 V2보다 단어·문장 출발 성능이 낮았지만 특수 토큰 구성이 더 일관됐다. 같은 모델 크기·같은 자모 출력이라도 공개 가중치별 차이가 컸다.

student-47 V5는 고정 조건의 성인 문장 비정답 304조합에서 오확정 0개로 Miniijune V2의 5개보다 유리했다. 반면 악기놀이 정답 통과는 65/106으로 V2의 93/106보다 낮았다. 따라서 V2가 모든 지표에서 우세한 것은 아니다. 짧은 단어를 잘 받아들이는 현재 목적에서 먼저 학습할 후보로 고르되, 잘못 통과시키는 것을 더 엄격하게 제한해야 하는 조건은 학습 후 두 후보를 함께 비교해야 한다.

Miniijune은 카드에 학습 자료·라벨 변환 규칙 설명이 충분하지 않다. 초성 ㅇ을 무음으로 해석하는 고정 자모 변환을 주 평가로 사용했고, 철자 G2P 해석을 적용한 보조 결과에서도 성인 문장 오류율은 8.2%였다. 모든 ㅇ을 소리로 세면 14.2%로 달라지므로, 실제 학습 연결 때는 자모 모양만 보고 라벨 규칙을 추정하지 말고 우리 목적에 맞는 규칙을 명시해야 한다. 최종 발음 안내 품질은 실제로 들린 소리의 라벨로 확인해야 한다.

**실행 재현성과 파일 검사**

193개 공개 저장소를 목록 또는 개별 파일로 검토했다. 실제 추론은 64개 체크포인트·서로 다른 가중치 63개로, 원본 녹음 718개에서 만든 3,157개 입력을 각각 실행했다. 주 실험은 202,048개 모델×입력 조합이며 이 중 앞선 세 모델의 검증된 출력 9,471개를 재사용했다. 새로 실행한 조합은 192,577개다. 중복 체크포인트와 파생 창을 독립 자료로 세지 않았다.

64개 중 두 모델은 전 입력을 추론하되 소리 오류율 순위에서 제외했다. miranoh는 42개 출력 기호의 발음 대응이 확인되지 않았다. thisisHJLee 1B sample5는 출력층 109칸에 비해 배포 토큰표가 93개이며, 공개 이력 66개에서도 완전한 표를 찾지 못했다. 후자는 모델 지정 blank 108로 CTC 번호열을 보존하고 누락 번호를 명시했다. 나머지 62개 체크포인트를 집계했다. 전체 명단·성적·실행 제외 사유는 [전체 결과표](WAV2VEC2_KOREAN_MODEL_RESULTS_2026-09-13.md)에 있다.

Transformers 5.15.0의 주 결과를 4.48.1 eager 실행으로 다시 확인했다. 체크포인트마다 고정한 16개 입력을 attention mask 없이/있이 각각 실행한 총 2,048회에서 모든 CTC 토큰열이 일치했다. 전체 3,157개를 모두 다른 버전에서 재실행했다는 뜻은 아니다.

기존 세 모델의 핵심 집계 576개가 이전 결과와 일치했고, 독립적인 RapidFuzz 계산과 대조한 서로 다른 소리열 쌍 54,023개에서 편집 거리 불일치가 없었다.

lsnoo 두 후보는 model config의 CTC blank 번호와 tokenizer의 pad 번호가 달랐다. 모델이 지정한 blank를 쓰도록 메모리 내 디코더를 연결하고 전 입력을 재시험했다. 다른 blank 해석도 보조 결과로 남겼다. daeinbangeu의 한 후보는 전처리 파일이 없었으나 thisisHJLee의 공개 체크포인트와 가중치·토큰표·실행 설정이 같음을 확인해 설정을 복원했다. 두 체크포인트의 전 입력 CTC 출력도 대조했다.

Miniijune V2의 출력 ID 41 매핑 공란과 출력 범위 밖 EOS 44는 공개 파일에 남아 있다. 이번 CTC 추론은 blank 43과 고정된 토큰 번호로 정상 실행됐다. 학습·Unity 디코더를 연결할 때 토큰 번호를 임의로 다시 매기거나 출력층을 실수로 재초기화하지 않도록 규칙을 고정해야 한다. 특수 토큰 경고 자체를 음성 인식 실패로 집계하지 않았다.

**무엇을 비교했는가**

목표는 우리 아동 자료로 파인튜닝할 출발 모델을 고르는 것이다. 현재 아동 학습 완료 모델과 공개 원본을 섞어 비교하지 않았다. 기존 모델도 `kresnik/wav2vec2-large-xlsr-korean`의 아동 학습 전 원본이다. 공개 후보들의 기존 학습 자료와 학습량은 서로 다르며, 이번 실험에서 새로 학습한 모델은 없다. Miniijune처럼 아동 발음을 대상으로 명명된 모델도 실제 학습 연령·자료 분할이 공개 카드에 없어 확인된 아동 성능으로 취급하지 않았다.

검색은 한국어·자모·IPA·phoneme 관련 목록과 `korean + wav2vec2` 목록을 합친 뒤 실제 config/vocab을 검사했다. 발견한 자모·음소 CTC 후보 중 가중치와 출력 매핑이 있는 후보를 실행하고, 기존 음절 방식과 대형 MMS·XLS-R 모델을 대조군으로 포함했다. 언어 모델, 목표 단어 강제 디코딩, 악기놀이 별칭과 임시 임계값 보정은 사용하지 않았다. 이름에 `with-LM`이 있는 저장소도 같은 greedy CTC 조건으로 평가했다. Whisper 등 모든 한국어 ASR 구조나 앞으로 새 출력층을 학습해야 하는 기반 모델까지 전부 비교한 실험은 아니다.

| 자료 | 원본 녹음 | 화자 | 해석 범위 |
|---|---:|---:|---|
| Common Voice 17 한국어 test | 208 | 21 | 20~40대라고 자기 기입한 공개 성인 문장 |
| Zeroth-Korean test | 457 | 10 | 읽기 문장 참고용. 개인별 연령 자료 없음 |
| 사용자 성인 녹음 | 7 | 1 | 잡아 5개·작아 2개 |
| 악기놀이 녹음 | 46 | 2 | 12개 표현. 연령 미확인으로 성인 집계에서 분리 |

총 718개 원본을 사용했다. 모델당 3,157개 입력은 전체 발화 1,263개, 겹치는 이동 창 1,812개, 생성 비음성 82개다. 파생 입력을 독립 녹음이나 새 화자로 세지 않았다. 원본 녹음과 문장을 바꾸지 않고 동일한 16kHz mono PCM을 모델마다 넣었으며, 각 입력의 SHA256을 확인했다.

[Common Voice 17 공개 미러](https://huggingface.co/datasets/fsicoli/common_voice_17_0)의 한국어 test 339개에서 연령 10대 33개와 연령 공란 98개를 제외했다. 성인 208개는 20대 151개·30대 27개·40대 30개다. 모델의 인식 결과를 보고 자료를 고르지 않았다. 미러 revision은 `8262c16bf297c87a9cd88c51997c4758ed7a8ba2`, 내려받은 test tar SHA256은 `ecc511693bc764d6266846b8e99b5b7180956b5b3c5b817a3bd7e172cbcb7c67`이며 CC0 자료다.

[Zeroth 원본 프로젝트](https://openslr.org/40/)와 [공개 미러](https://huggingface.co/datasets/kresnik/zeroth_korean)의 test를 사용했다(CC BY 4.0). 미러 revision은 `1fe937899f828af822293d05e086200946088bdf`, parquet SHA256은 `2f6382b902622ede1bf35e5a167a9b06b0f1b8c896e1947324b8b5180fca7502`다.

**점수가 뜻하는 것**

전사 문장을 프로젝트 G2P로 바꾼 기준 소리열과 모델 출력을 비교했다. 소리 오류율은 `(치환+삭제+삽입)/기준 소리 수`이며, 삽입이 많으면 100%를 넘을 수 있다. `샅/삳`, `잡아/자바`처럼 해당 문맥에서 같은 발음으로 변환되면 철자 차이로 감점하지 않는다. 모든 출력과 기준에 같은 ㅐ/ㅔ 병합과 ㄹ 표기 통일을 적용했다. `놔/와`, `잡아/작아`의 소리 차이는 보존했다.

**이 지표는 전문가가 실제로 들은 발음의 전사와 비교한 PER이 아니다.** 기준 문장의 G2P와 다른 정상 발음 변이도 오차에 포함될 수 있다. 문장 전체 일치는 소리 하나만 달라도 실패하므로 단어 통과율과 같지 않다. 모델 출력과 목표가 다르다는 사실만으로 아동이 잘못 발음했다고 결론낼 수 없다.

모델마다 공개된 출력 단위에 맞는 변환을 적용했다. 음절·철자 자모는 문자 조합 후 같은 G2P를 사용하고, MFA/IPA와 발음 자모 후보는 고정된 소리 변환을 사용했다. 미등록 기호와 잘못 출력한 외국 문자는 버리지 않고 오류에 포함했다. 규칙이 불명확한 자모의 직접 소리 변환/철자 G2P 해석, IPA 위치 해석, CTC blank 설정의 다른 해석도 별도 민감도 결과로 남겼다. 녹음마다 가장 높은 점수를 내는 디코더를 골라 합치지 않았다.

학습 이력에 따른 자료 친숙도를 함께 해석해야 한다. [기존 kresnik 원본](https://huggingface.co/kresnik/wav2vec2-large-xlsr-korean)과 일부 자모 모델은 Zeroth 학습 이력이 있고, [kresnik 300M 대조군](https://huggingface.co/kresnik/wav2vec2-large-xls-r-300m-korean)은 Common Voice 13 학습 이력이 있다. Common Voice 17과의 녹음 단위 중복은 확인하지 못했다. 이 점수를 모두 미지 자료의 성능이라고 부르거나, 서로 다른 자료의 점수를 단순 합쳐 최종 순위로 삼지 않았다. 다른 후보의 학습 자료 중복도 완전히 배제할 수 없다.

**입력 변화와 악기놀이 판정**

보유 단어 53개에는 앞뒤 무음 각 1초, 음량 −12dB, SNR 20/10dB 백색잡음, 0.9/1.1배 재생, 100ms 뒤 0.3배 크기의 반사음 조건을 적용했다. 재생 속도 변형은 피치도 함께 바뀌며 아동 목소리로 바꾸는 작업이 아니다. 인공 반사음은 실제 방의 충격응답이 아니다. 낮은 음량만 바꾼 결과에는 표준 파형 정규화의 영향이 있으므로 조용하게 말하는 사람이나 낮은 SNR에 대한 보장으로 해석하지 않는다.

공개 자료 변형·이동 창에는 각 화자의 원본 SHA256 순으로 최대 2개씩 미리 정한 58개(Common Voice 38·Zeroth 20)를 사용했다. 이 자료에는 앞뒤 무음과 SNR 20/10dB 조건을 적용했다. 모든 모델에 같은 잡음 파형을 넣었다. SNR의 기준은 원음의 활성 20ms 구간 RMS다.

이동 창은 1.5/2.5/4초, 이동 간격은 0.5초다. 파일 시작 전에는 0을 채우고 발화 뒤 여유 구간을 포함했다. 공개 문장은 2.5초 창을 사용했다. 겹치는 두 창의 연속 통과는 서로 독립적인 두 번의 발화를 뜻하지 않는다.

정답 판정은 복원된 공통 `Matcher.for_streaming`과 `ko_child_v2` 행렬을 동일하게 사용했다. 검사한 임계값은 0.70/0.80/0.85/0.90/0.95/1.00, 연속 조건은 1/2/3회다. 핵심 표는 비교 전에 정한 임계값 0.90·2.5초 창·연속 2회다. 아동용 혼동 행렬을 모든 후보에 공통 적용한 진단이며, 후보별 최적 조건이나 같은 실사용 오확정률을 달성하도록 별도 보정한 결과가 아니다.

보유 단어는 라벨이 해당 단계 정답표에 있으면 양성, 없으면 음성으로 분류했다. 공개 문장은 기준 소리열에 그 단계의 정답 소리열이 연속해서 등장하는 경우를 음성 집계에서 제외했다. 분모는 녹음×단계 조합이며 같은 녹음이 여러 단계에 반복 사용된다. ‘흔들어’ 안의 ‘들어’처럼 부분 매칭에서 충돌하는 경우는 모델이 정확히 들었어도 정답표 기준 오확정으로 잡힐 수 있어 별도 원인을 기록했다.

비음성 82개는 2.5/5초의 무음, 백색잡음, 300Hz 저역 잡음, 톤, 클릭이다. 실제 악기 소리·생활 소음이나 연속 VAD 세션을 대체하지 않는다. 비음성에서 보고하는 임계값 도달은 입력 한 개의 진단이며 실제 서비스의 연속 확정 오확정률이 아니다.

**검증과 다음 단계의 경계**

가중치 파일 크기와 공개 LFS SHA256, 실제 로딩 시 누락·불일치 가중치, 출력층 크기와 blank 번호를 확인했다. 저장소의 원격 사용자 코드는 실행하지 않았다. 직접 계산한 편집 거리는 별도 RapidFuzz 구현과 대조하고, 이전 세 모델의 핵심 집계가 그대로 유지되는지도 확인했다. 실행 라이브러리 버전을 바꾼 검사와 입력 마스크 유무 검사도 같은 고정 입력으로 진행했다.

화자 단위 5,000회 부트스트랩(seed 9132026)으로 후보 간 차이의 표본 내 변동을 계산했다. 여러 후보를 본 뒤 고른 순위의 탐색적 구간이며 다중 비교를 보정한 확정적 우열이나 한국 아동 전체의 성능 구간이 아니다.

이번 결과로 정하는 것은 **아동 파인튜닝의 우선 후보**다. 학습에는 동일한 아동 자료·화자 분할·비교 가능한 학습 예산을 사용하고, 평가 화자는 학습과 임계값 조정에서 제외해야 한다. 발음 오류 안내를 만들 목적이면 정답 문장의 철자뿐 아니라 실제로 발음된 소리를 보존하는 라벨이 필요하다. 잘 읽은 발음에 대한 잘못된 지적과 실제 차이를 놓치는 비율은 그 라벨로 별도 측정해야 한다. ONNX 변환, Unity 출력 일치·지연·메모리 검증은 모델 선택 후의 작업이며 이번에 측정하지 않았다.
