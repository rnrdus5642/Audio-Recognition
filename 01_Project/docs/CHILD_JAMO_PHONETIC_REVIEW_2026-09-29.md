# 실제 소리 표기 확인과 같은 문장의 다른 화자 비교

2026-09-29. 사용자의 다음 단계 진행 요청에 따라 **15문항을 준비했다.**
기존 20문항에서 보고한 차이 5건을 학습 정답으로 옮기려면 정확히 어떤 소리였는지
별도로 확인해야 한다. 또 수정한 녹음을 외우는 효과와 다른 화자에게도 통하는 효과를
구분할 평가 자료가 필요하다. 이번 단계는 그 두 조건을 확인한다.

청취: <http://127.0.0.1:8778/>

## 사용자가 확인할 것

1. 소리를 한 번 듣고 비교 표기를 연다.
2. 문장 전체가 분명히 같은 소리로 들리는 표기가 있으면 선택하고 전체 확인에 체크한다.
3. 둘 다 가능하거나 일부만 확실하면 해당 판단 항목을 고른다. 보기와 다른 소리도 선택할 수 있다.
4. 저장하고 다음으로 이동한다. 메모는 선택이다.

앞·뒤가 잘린 것 같을 때만 펼쳐 원본을 들을 수 있다. 이전 10번의 원본 비교는
이미 완료했으며, 이번 질문은 실제 소리 표기를 확정할 수 있는지를 묻는다.
모델 출력·학습용/평가용 역할은 페이지에 표시하지 않는다.

## 준비한 자료

| 확인 대상 | 수 | 목적 |
|---|---:|---|
| 기존 불일치 보고 녹음 | 5 | 문장 전체의 실제 소리 표기 확인 |
| 같은 전사 문장의 다른 화자 녹음 | 10 | 문장마다 2명, 정상 표기와 다른 소리의 대조가 실제로 있는지 확인 |

총 15명, 판단 구간 합계 58.214초다. 아래 번호는 새 페이지 기준이다.

| 원래 전사 | 기존 검토 번호 → 새 번호 | 새 화자 문항 |
|---|---|---|
| 반가워요 | 3 → 2 | 1, 9 |
| 백화점에 가요 | 4 → 10 | 5, 8 |
| 고양이가 졸아요 | 6 → 7 | 4, 11 |
| 장미가 예뻐요 | 10 → 13 | 3, 14 |
| 기뻤어요 | 15 → 15 | 6, 12 |

새 녹음은 원본 색인에서 같은 정규화 전사를 찾고, 고정한 해시 순서로 문장마다 2개를
선정했다. 5개 문장의 적격 후보는 각각 16·11·11·10·10개였다. 음성을 듣거나 모델
출력을 보기 전에 목록을 고정했다. 어려운 녹음이라고 듣고 난 뒤 바꾸지 않는다.

새 10개는 기존 train/valid/test의 녹음 목록에 모두 없고, 그 화자 10명은 **현재 모델의
본학습 train 화자 890명과 겹치지 않는다.** 다만 다른 녹음이 기존 valid에 포함된
화자들이므로 개발용 비교 자료다. 사전학습까지 미노출인 화자나 완전히 손대지 않은
최종 시험 자료라고 주장하지 않는다. 원본의 `subset=train`과 이 프로젝트의 화자별
`split=valid`는 다른 분류다.

원본 JSON의 파일명·전사·길이·시작/끝·화자·나이와 색인을 대조했다. 새 음성은 TAR
멤버의 이름·크기·바이트 위치를 검증했고, 기존 5개는 본학습에 쓴 PCM과 정확히 같다.
15개 모두 기존의 시작/끝 + 0.25초 여백 정책을 유지했으며, 길이가 달라진 9개는 전체
원본을 함께 제공한다. 저장한 FLOAT WAV의 PCM은 변환 전 float32 배열과 정확히 같다.

## 답변을 해석하는 기준

- 보기는 기존 학습 표기와 이전 메모에서 만든 **미확정 가설**이다. 메모를 G2P에 넣어
  정답으로 만든 것이 아니다. 예를 들어 이전 `백화강에가요` 메모를 토대로 제시한
  `배콰강에 가요`도 전체 소리가 맞다는 선택 없이는 정답이 아니다.
- 보기의 문장 전체를 선택하고 확인한 경우만, 그 표기를 G2P에 다시 통과시키지 않고
  문자 그대로 자모로 분해한다. 이는 한 청취자의 넓은 한글/자모 전사이며 전문가의
  정밀 음성 전사나 임상 판정이 아니다.
- 애매함·일부만 확실함·다른 소리·청취 불가 답변에는 학습 정답을 만들지 않는다.
  처음 들린 말과 추가 메모는 보존하되 정답으로 자동 승격하지 않는다.
- 원본 비교에서 잘림 또는 불확실을 선택하면 전체 표기를 골랐더라도 라벨 후보에서
  제외한다. 음성 구간과 소리 표기의 대응을 먼저 확인해야 한다.
- 문장이 같다는 사실만으로 발음 대조가 확보됐다고 세지 않는다.

## 답변 후 이어서 할 일

`analyze_phonetic.py`가 15개 답변과 이력을 읽기 전용으로 가져와 다음을 판정한다.

1. 기존 5개 중 전체 소리가 확인되어 학습 표기를 바꿀 근거가 생긴 항목.
2. 각 수정 항목과 **같은 변경 표기**를 확인한 새 화자 및 기존 표기로 확인한 새 화자가
   모두 있는지. 최소 서로 다른 2명의 정상/변이 대조가 있어야 해당 비교가 준비된 것으로 센다.
3. 조건을 충족한 대조만 비교 실험에 포함한다. 원래 라벨과 확인된 소리 라벨 두 조건의
   음성·재생 순서·추가 학습량·최적화 조건을 동일하게 고정한다.
4. 학습 항목 적합도, 다른 화자에서의 자모 오류, 정상 발음을 잘못 바꾸는 비율, 기존
   검증셋의 퇴행을 각각 보고한다. 학습한 5개를 잘 맞히는 것만으로 개선이라고 하지 않는다.

현재는 청취 답변 대기다. **새 학습은 시작하지 않았고 마이크 모델도 바꾸지 않았다.**
새 화자의 녹음이 모두 기존 표기대로라면 변이 일반화 자료가 부족하다는 결론이 된다.
그 경우 모델 출력이나 원래 전사를 실제 발음 정답으로 대신 넣어 실험하지 않는다.
15개는 탐색용 소수 표본이며 전체 데이터셋의 오류율이나 모든 자모의 개선을 추정할 수 없다.
