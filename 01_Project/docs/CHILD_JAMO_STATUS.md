### 초성 누락과 blank

`blank`는 해당 시점에 자모를 출력하지 않는 CTC 후보다. 무음이나 띄어쓰기의 판정이
아니며, 말소리가 있는 프레임에도 나올 수 있다. 현재 구현은 프레임마다 최고 점수를
선택하고, 연속된 같은 토큰을 합친 뒤 blank를 제거한다. softmax 전후의 최고점 순서는
같다. 자모 조합 단계는 빠진 초성을 추측해 채우거나 이미 나온 자모를 버리지 않는다.

아래는 동작 설명용 예시이며 실제 녹음의 프레임 기록은 아니다.

```text
blank → ㅊ → blank → ㅐ → ㄱ      ⇒ 책
blank → blank → blank → ㅐ → ㄱ  ⇒ ㅐㄱ
```

**blank의 존재는 정상 동작이지만, 발음한 자음이 최종 자모열에서 빠지는 것은 오류다.**
개별 누락은 필요한 자음이 blank·다른 후보에 밀렸는지, 반복 토큰의 병합과 관련됐는지
프레임 경로로 구분해야 한다. 토큰이 선택된 시점이 실제 발음 구간과 정확히 일치한다고
가정하지 않는다. 초성 `ㅇ`은 별도의 자음 소리가 없는 표기이므로 음향 해석도 구분한다.

이전 `personal:child1_17`은 사용자 청취 기준 `쌕`, greedy 결과 `ㅐㄱ`이었다.
`ㅆ`의 최대 프레임 softmax 값은 약 0.00016(0.016%)이었고 빔 탐색 결과는 `책`이었다.
올바른 초성 후보의 점수가 낮았다는 근거이며, 사람이 그 소리를 발음했을 확률은 아니다.
이 사례를 “책의 ㅊ만 복구하면 해결”로 해석하지 않는다.

1. 16번의 `책 → 짹`은 사용자 청취 기준의 수정 후보로 보존한다. 기존 20개는 이미
   본학습에 쓰였으므로 일반화 평가 자료로 사용하지 않는다. 8번의 `책 → 채` 출력은
   별도 관찰로 유지하고, 18번·`방가워우요/방가워요` 등의 불확실성은 그대로 둔다.
2. 기존 색인에서 학습 화자를 제외하고, 본학습 train/valid/test의 녹음 및 이전 제시
   녹음을 제외한 개발 후보를 찾았다. 5~7세 범위에서 단독 `책` 전사 후보는 **10개·9명**,
   원본 길이 합계 30.080초다. 이 9명은 다른 녹음이 본학습 valid에 있어 개발용으로
   구분하며 최종 test 화자는 모집하지 않았다. 아직 후보 음성을 추출·청취하거나 실제
   발음 라벨을 검증한 상태는 아니다.
3. 같은 기준의 단독 `짹` 전사 후보는 0개다. `짹짹짹` 등이 포함된 문장 전사는 있으므로
   모델이 `짹` 관련 자모를 전혀 학습하지 않았다는 뜻은 아니다. `책` 전사 후보에서
   실제로 `짹`이 발음됐는지도 아직 모른다. 우선 후보를 검증해 평가용 `책`·`짹`을
   확보하고, 분명한 `짹`이 없으면 별도 녹음·전사로 보완한다. 녹음 지시 문구만으로
   실제 발음을 정답 처리하지 않는다.
4. 발음 판단과 평가 자료가 준비되면 동일 음성·동일 학습 조건에서 원래 라벨 조건과
   수정 라벨 조건을 비교한다. 다른 화자의 `짹` 구별 개선, `책` 유지, 기존 검증 성능의
   퇴행을 함께 본다. 그 결과를 확인한 뒤 다른 발음 대조로 확대한다.
