표기 변환 자체가 코드대로 동작해도 목적에 맞는 발음 정답이라고 보장할 수 없다.

기존 청취에서 보고된 불일치와 전사 기반 라벨의 한계는 이미 기록되어 있다.

## 자동 확인 결과와 한계

- 20개 모두 원본 WAV의 TAR 항목명·바이트·해시가 학습 기록과 일치한다.
- 원본 JSON 항목명·해시, 전사, 시작·끝 시각, 파일 길이를 학습 행과 대조했다.
- 원본 전사에 현재의 동결된 라벨 코드를 적용한 정규화 문구·G2P 표기·토큰 ID가
  기존 학습 정답과 **20개 모두 일치**한다. 이 표본에서 조인·전사 변환 재현 오류는 발견되지 않았다.
- 학습 PCM의 길이·해시와 웹에서 재생하는 WAV의 PCM이 모두 정확히 일치한다.
  별도 음량 보정, 무음 추가, 속도 변화는 적용하지 않았다.
- 15개는 학습 시 원본에서 일부 구간을 잘랐고, 5개는 전체 원본과 같다.
  15개에는 자르기 전 원본을 함께 제공한다. 자른 사실만으로 말소리를 잘랐다고 판단하지 않는다.
- 학습 음성 재생 길이의 합은 79.814초다. 비교·메모·재생 반복을 포함한 예상 청취 시간은 5~8분이다.

**변환이 재현된다는 사실은 소리와 정답이 맞다는 보증이 아니다.** 원본에 기록된
시각대로 잘랐다는 확인도 그 시각이 음성학적으로 올바르다는 보증은 아니다.

## 판단 방법

소리를 먼저 듣고 표기를 열게 한다. 첫 인상 메모는 선택이며 표기를 열 때 최초 내용을
보존한다. 대조 문항은 어느 보기가 학습 정답인지 표시하지 않고 순서도 고정 시드로 섞었다.
「둘 이상으로 들림」「보기와 다름」「말소리 없음」「판단 어려움」을 별도로 남긴다.
발음 메모는 필수가 아니며, 들린 말을 맞춤법대로 적어도 정밀 발음 정답으로 자동 변환하지 않는다.

시작·끝이 잘린 것 같으면 원본도 듣고, 원본에서도 같은 소리인지 또는 학습 구간에서
말소리가 사라졌는지를 선택할 수 있다. 이 판단은 전체 발음 선택과 별도로 저장된다.

화자와 발음 대조가 분리된 조건에서 라벨 수정의 효과를 비교한다.
