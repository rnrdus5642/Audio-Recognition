# 오디오 정답 처리 — 공용 모델 패키지

Unity 2022.3 / Sentis 1.2.0-exp.2, Windows PC·PC 연결 VR용입니다. HuBERT 정서법 자모 모델과 web v4 후처리를 사용합니다. GPUCompute 경로를 유지합니다.

## 사용 방법
`Tools > 오디오 정답 처리 기능`에 세 메뉴만 제공합니다.

- **초기 세팅**: 메뉴를 누르면 바로 실행하며 화면 중앙 진행창에 현재 단계와 진행률(%)을 표시합니다. 취소 버튼으로 중단할 수 있고 완료·실패·취소 시 자동으로 닫힙니다. 엔진 설치 단계는 UPM이 진행률을 제공하지 않아 단계 안내만 표시합니다. 완료·실패 내용은 Console에도 남깁니다. 추론 엔진·정답 데이터·공용 모델을 확인합니다. Windows 문서/오디오정답처리/Models의 정상 모델은 재사용하고, 없거나 손상됐으면 GitHub Release에서 자동 설치합니다. 위치 선택·수동 등록은 없습니다. 한 PC의 모든 콘텐츠가 같은 파일을 읽습니다.
- **음성 테스트**: 마이크와 단계를 선택해 게임과 같은 모델·정답·후처리로 확인합니다.
- **정답 단어 설정**: 현재 프로젝트의 단계별 표현을 편집·검증·저장합니다. 끝의 물음표는 표시용으로 유지하며 재학습은 필요 없습니다.

프로젝트 연결은 Assets/Resources/CRC/AudioAnswerProject.json의 displayName과 targetsResourcePath를 사용합니다. 정답 JSON은 프로젝트 Assets에 보관합니다. 현재 세 콘텐츠는 각각 9절차입니다.
정답 단어의 비교용 IPA는 내장 한국어 발음 규칙과 자모 변환 코드로 만듭니다. 별도 IPA 모델이나 Python 설치는 필요 없습니다.

## 모델
파일: hubert_ko_child_jamo_sentis1.sentis, 3,851,161,113 bytes.
SHA-256: f676db58234bd48f5e4530211e623248afbb22a972c54b89a39288eb07ef29ff.
배포: https://github.com/rnrdus5642/Audio-Recognition/releases/tag/model-v3-child-jamo-sentis1

다운로드와 SHA-256 검증은 백그라운드에서 진행하고 검증 후 원자적으로 설치합니다. 취소·손상·동시 설치를 처리합니다. 설치기가 `.verified` 표식을 남기며 Runtime은 크기·수정 시각·표식을 확인한 뒤 읽기 전용 FileStream에서 로드합니다. 게임 스레드에서 전체 해시를 다시 계산하지 않습니다.
Windows 빌드 앱은 시작 화면에서 같은 문서 위치를 확인합니다. 정상 설치 기록이 있으면 파일 크기·수정 시각·작은 표식만 읽고 게임을 시작합니다. 기록이 없거나 파일이 변경됐으면 백그라운드에서 전체 검증하며, 파일이 없거나 손상됐으면 공개 Release에서 다운로드합니다. 진행 단계·퍼센트·취소·실패 시 다시 시도·종료 버튼을 표시합니다. 모델은 빌드에 포함되지 않으며 새 PC에서 Unity나 Python을 설치할 필요가 없습니다. 최초 다운로드에는 인터넷과 모델 약 3.85GB를 저장할 공간이 필요합니다. 교체 중에는 기존 파일과 임시 파일이 함께 존재할 수 있습니다.

개발자는 초기 세팅을 한 번 실행한 뒤 Windows로 빌드합니다. 초기 세팅은 패키지 시작 씬을 `Assets/AudioAnswerStartup/AudioModelStartup.unity`에 복사해 Build Settings 첫 씬에 추가하고, 원래 첫 번째 게임 씬을 `Assets/Resources/CRC/AudioAnswerLaunch.json`에 기록합니다. 시작 씬 확인이 끝나야 기존 게임 씬을 로드하므로 설치 중 게임·마이크 초기화가 시작되지 않습니다. 사용자 빌드 스크립트도 이 시작 씬을 첫 항목으로 포함해야 합니다. 기존 씬 인덱스가 한 칸 이동하므로 새 콘텐츠에서 숫자 인덱스로 씬을 불러오는 코드가 있다면 경로나 이름을 사용하세요.

초기 세팅 메뉴를 직접 누르면 전체 SHA-256을 재검사하므로 이미 설치된 PC에서도 시간이 걸릴 수 있습니다. 정상 빌드 앱의 반복 실행에서는 이 검사를 생략하지만 모델 메모리 로드와 GPU 준비 시간은 별도로 필요합니다. PC 연결 VR의 최초 설치 화면은 PC 창에 표시됩니다.

현재 공유 바이너리는 Sentis 1.2 전용입니다. Unity 6용 모델·외부 로더와 CPU 자동 전환은 이번 범위에 포함하지 않습니다. 이전 API는 호환용으로 남겨 두되 구형 설치·발표 메뉴는 노출하지 않습니다. [이전 버전 문서](Documentation~/legacy-package-0.8.7.md)는 역사적 참고 자료입니다.
