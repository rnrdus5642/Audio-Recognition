# 3세 음성 듣기

현재 AIHub 108의 오디오 검증 카탈로그에서 3세 녹음 전체를 읽는 로컬 청취 웹이다.
학습·검증·시험 후보와 기존 보류 자료를 포함한다. 모델 추론과 학습은 수행하지 않는다.

워크스페이스 루트에서 실행:

```powershell
powershell -ExecutionPolicy Bypass -File .\05_Run\start_age3_review.ps1
```

주소는 <http://127.0.0.1:8781/>. 실행 스크립트가 숨김 서버를 시작하고 브라우저를 연다.
이미 같은 앱이 실행 중이면 재사용한다. `-NoBrowser`로 브라우저 자동 열기를 끌 수 있다.

- 처음에는 원문 라벨과 목록 문장을 가린다. 재생 후 **라벨 보기** 또는 가리기 해제로 비교한다.
- 단어·문장 검색, 화자·자료 구분·검토 상태·길이 필터, 화자 골고루/무작위/길이순 정렬을 지원한다.
- 화자 골고루는 현재 필터에 해당하는 화자를 한 번씩 순회하는 목록 순서다. 통계 표본 추출이나 학습 설정이 아니다.
- 브라우저 기본 음성 재생, 실제 WAV 파형 탐색, 재생 속도, 다음 녹음 자동 재생을 제공한다.
- **들리는 정도**와 **라벨과의 관계**를 구분하고, 들린 말과 메모를 선택적으로 기록한다.
- 입력 중 메모는 브라우저 임시 저장이다. **저장** 또는 **저장하고 다음**을 눌러 검토 기록에 반영한다.
- 검토는 SQLite에 영구 저장하고 수정 이력을 남긴다. 다른 창에서 같은 메모를 수정하면 충돌을 알린다.
- **검토 기록 내보내기**는 원본 식별자·라벨·음성 SHA-256·판단·메모·수정 이력을 JSON으로 내려받는다.

로컬 상태는 `02_Datasets/검토/3세_청취/`에 저장한다.
`catalog.sqlite3`는 재생성 가능한 색인, `reviews.sqlite3`는 사용자의 검토 기록이다.
원본 WAV·라벨·학습 분할·모델은 수정하지 않으며 검토 결과를 학습에 자동 반영하지 않는다.
자료 구분의 보류는 기존 자동 점검 결과이며, 나머지 자료의 발음 정확성을 보증하지 않는다.

서버는 `127.0.0.1`에만 바인딩한다. 종료할 때 `/health`에 표시된 PID가 이 앱인지 확인하고
`Stop-Process -Id <PID>`를 사용한다. 기본 실행은 웹을 닫아도 서버가 계속 실행된다.

브라우저 QA는 설치된 Edge와 Playwright를 사용하며 `--reviews-db`로 사용자 답변과 분리한
시험 데이터베이스를 지정해야 한다. 실제 검토 기록에 시험 답변을 쓰지 않는다.
