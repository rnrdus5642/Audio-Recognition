# 어휘 확장 후보 검증 (2026-09-06)

커리큘럼 29단어 중 `놔`·`놔요` 두 개가 배포 출력 1205항목으로는 정확히
전사될 수 없습니다. 이 단계에서 한 일은 **그 사실을 자동으로 잡아내는 검사**와
**어휘를 1206으로 넓힌 학습 전 후보**를 만든 것까지입니다. 배포 모델 · 어휘 ·
정답 · 임계값 · Unity 런타임 코드는 하나도 바뀌지 않았습니다.
기존 아동 파인튜닝 가중치는 보존했으며, 새로 추가한 `놔` 출력 행만 아직
음성으로 학습하지 않았습니다.

**후속 상태: 문서 정리 후 보류.** 누락 철자는 `놔`뿐 아니라 분할에 배정된
아동 전사에서 523종이다. 같은 단독 IPA를 내는 기존 글자가 있는 110종을
제외하면 413종이며, 그 안의 고유 IPA 조합은 391가지다. 문맥·음향 학습을
포함한 최소 추가 출력 수는 아니다. 사용자 요청으로 확장·라벨 통합·추가 학습·
배포는 진행하지 않는다. [어휘·IPA 후속 분석](../../../docs/VOCABULARY_IPA_COVERAGE_2026-09-06.md)에
검사 범위와 재개 시 판단 사항을 정리했다. 아래는 `놔` 후보 준비 당시의 기록이다.

이 문서는 이번 단계의 기록입니다. README 에 있는 201개 테스트 · epoch-05 ·
2026-08-19 튜닝 수치는 그때 잰 값이고 그대로 둡니다.

## 후보에서 확인한 것

```
음향 출력      1205 → 1206
새 음절        놔 = 1205
유지된 id      1205개 전부 제자리 (blank 1204 · unk 1203 · 구분자 859)
출력 밖        <s> 1206 · </s> 1207   (토크나이저 길이 1208 ≠ 음향 폭)
config         bos/eos = null, pad = 1204
가중치         파라미터 424개 대조, lm_head 기존 1205행 포함 전부 비트 일치
```

합성 골든 6클립을 원본과 후보에 각각 통과시켰습니다. 전사가 달라진 클립 0개,
새 토큰이 이긴 프레임 0개, 기존 열 최대차 0.00e+00.

```
put_polite_f  놔요 → '나요'      put_plain_f  놔 → '나'
put_polite_m  놔요 → '와요'      put_plain_m  놔 → '뭐'
mom_f/mom_m   엄마 → '엄마'
```

**이것은 인식이 좋아졌다는 증거가 아닙니다.** 확장 전후 이 6클립의 기존
출력이 유지됐다는 관측이며, 모든 입력에서 출력이 같다는 보장은 아닙니다.
새 행은 아직 음성으로 학습하지 않았고, 합성 TTS 결과로 아동 정확도를
판단할 수도 없습니다.

낮은 bias(-10)는 새 행이 argmax 를 이기지 못하게 "덜" 만들 뿐 보장이
아닙니다. 상수 bias 보다 학습된 로짓이 전부 낮은 프레임이 있으면 새 행이
이깁니다. 그래서 도구는 성질을 주장하지 않고 클립에서 이긴 프레임 수를 셉니다.

두 환경에서 같은 값이 나옵니다: transformers 4.57.6 / 5.15.0 모두
`config.vocab_size` 1206, `tokenizer.vocab_size` 1206, `len(tokenizer)` 1208.

## 코퍼스 근거

인덱스 2,765,817행을 훑고 **분할에 배정된 전사** 기준으로 셌습니다. `놔` 가
있고 다른 어휘 밖 음절은 없으며 1~15초인 발화입니다.

| 분할 | 발화 | 화자 | 초 |
|---|---|---|---|
| train | 235 | 179 | 1,420.4 |
| dev (train 화자에서 분리) | 11 | 10 | 63.4 |
| valid | 74 | 54 | 423.2 |
| test | 63 | 44 | 401.0 |

383개 전부 16kHz 모노로 열립니다 — **헤더만** 확인했고 라벨 정확도와 음향
품질은 확인하지 않았습니다. 감사 시점의 manifest 정규화를 쓴 수치이며, 그 뒤에
`normalise()` 가 NFC 를 먼저 합성하도록 고쳐졌지만 전체를 다시 세지는
않았습니다.

`놔`·`놔요` 를 단독으로 말한 발화는 0건입니다. 학습을 하더라도 단어 단위
정확도를 이 코퍼스로는 잴 수 없다는 뜻입니다.

오래 적혀 있던 "코퍼스에 64건뿐" 은 틀린 수치였고, 거기 기대던 "학습으로
메우기 어렵다 / 다른 동사로 바꾸는 것이 맞다" 는 근거가 확인되지 않았습니다.
반대로 학습이 된다는 근거도 없습니다.
