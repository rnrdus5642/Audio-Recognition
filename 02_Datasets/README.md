# 학습 데이터 위치

이 폴더에는 로컬 학습 자료를 둔다.

- `AIHUB/`: 원본 음성·라벨 TAR
- `AIHUB정리/`: 원본 인덱스, 화자 분할과 분석 목록
- `audio/`: 이전에 추출한 연령별 음성

Git에는 이 안내문만 보존한다. 원본·색인·음성 파일은 Git에서 제외하며 로컬에서 유지한다.
현재 학습 도구의 데이터 위치는 `01_Project/python/workspace.py`의 `DATASETS`를 따른다.
개별 TAR·분할·라벨의 계약과 검증을 거쳐 사용하며, 폴더 이름만 같은 다른 자료로 대체하지 않는다.
