## 추가 자유대화 음성 정리 (AIHub 108)

2026-10-27 사용자가 다운로드한 [AIHub 자유대화 음성](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=108)의
원천 ZIP 9개(266.78GB)를 바탕화면에서 `AIHUB_108/archives/Training`, `Validation`으로 이동했다.
동일 C 드라이브 이동 전후 파일 ID·크기·수정 시간이 일치하며 원천 ZIP은 모두 보존한다.
기존 라벨 ZIP 6개(3.46GB)는 `AIHUB_108/labels/`에 있고 바탕화면의 이전 라벨 사본도 유지했다.

3~6세 라벨 **567,999개 모두**에 대응하는 음성을 찾아 `AIHUB_108/audio/03세~06세/화자키/`에
추출했다. WAV 합계는 **60.13GB**, 실제 녹음 길이 합계는 **521.75시간**이다.

| 라벨 연령 | 고유 녹음자 ID | 추출 WAV | 실제 음성 시간 |
|---|---:|---:|---:|
| 3세 | 74 | 25,852 | 26.27시간 |
| 4세 | 147 | 84,626 | 79.19시간 |
| 5세 | 244 | 171,791 | 160.42시간 |
| 6세 | 346 | 285,730 | 255.87시간 |
| 합계 | 811 | 567,999 | 521.75시간 |

연령은 원래 JSON의 숫자 `age` 기준이며 만 나이 적용 여부는 확인되지 않았다.
녹음자 ID 수는 실제 인물별 신원 검증 결과가 아니며 기존 데이터의 화자 수와 단순 합산하지 않는다.
시간은 파일 전체 길이로 무음을 포함한다. 기존 라벨의 메타데이터 합계는 521.74시간이었다.

선정 파일 전체의 ZIP CRC를 검사했고 저장된 WAV를 다시 읽어 원본 SHA-256과 대조했다.
선정하지 않은 연령의 ZIP 본문은 전수 검사하지 않았다. 원본 1개는 확장자가 `.wavp`였으며,
정상 RIFF/WAVE·동일 파일명 본체·라벨 길이를 확인하고 추출본 확장자만 `.wav`로 정리했다.
음성 내용·샘플링·구간은 변경하지 않았다. 9개 ZIP 각각에 대상 연령 파일이 있음을 확인했다.

음성 형식은 `audio-verified-summary.json`의 `audio_format_counts`에 전수 집계했다.
길이 불일치·무음·중복과 해석이 필요한 원문 표기는 검토 목록으로 분리한다. 사람이 전체 녹음을
듣고 전사의 정확성을 확인했다는 뜻은 아니다. 결과는 [음성 정리 결과](AIHUB_108/음성_정리_결과.txt)에 있다.

이전 글자 모델에는 여전히 `놔` 출력 항목이 없어서 `놔`·`놔요`의 정확한 철자 출력이 불가능하다.
새 라벨에는 `놔`를 포함한 문장 79개, `놔요` 포함 문장 5개가 있으나 해당 단어만 말한 단독 발화는 없다.
이번 정리는 데이터 확보 작업이며 모델의 인식 성능이 바뀌었다는 의미가 아니다.

## 원문 라벨 자모 학습 준비

확정 방향은 **데이터셋의 원래 철자를 유지하고, 발음형/G2P 변환 없이 자모로 분해해 학습**하는 것이다.
`학습준비/자모_원문라벨_3-6세/`와 `학습목록/다음 학습 - 자모 원문 라벨 (3-6세).lnk`에서 자료를 찾는다.
원문은 `label_original`, 명확한 구두점·공백만 정리한 철자는 `label_text`에 보존한다.
괄호·숫자·전사 태그는 임의로 지우지 않는다. 어휘는 위치별 자모 67종과 blank·공백, 총 69항목이다.
현대 한글 11,172음절과 목표 29단어의 표현 가능성을 확인했으며 이는 인식 성능 검사가 아니다.

| 학습·평가 후보 | 학습 | 검증 | 테스트 | 합계 시간 |
|---|---:|---:|---:|---:|
| 기존 AIHub 540 | 222,483개 / 297.42시간 | 65,092개 / 86.83시간 | 62,530개 / 83.89시간 | 468.14시간 |
| 새 AIHub 108: 음성 검증 완료 | 417,810개 / 380.85시간 | 55,561개 / 52.39시간 | 56,073개 / 48.95시간 | 482.19시간 |

540 시간은 원본 메타데이터, 108 시간은 실제 WAV 길이다. 모두 구간 자르기 전의 파일 전체 길이다.
새 데이터 검토 목록은 **38,555개**로, 기존 표기 검토 38,524개에 음성 점검으로
**31개**가 추가됐다. 기존 540 검토 자료 5,833개도 보존한다.
검토 자료를 삭제하거나 라벨을 발음형으로 고치지 않았다.

2026-10-27 사용자 결정으로 **NO·SP·SN·FP 태그가 하나라도 붙은 발화 38,479개 전체를
학습·검증·테스트에서 제외**한다. 태그만 지우고 문장을 다시 넣지 않는다.
전부 기존 검토 목록에 있어 위 학습·평가 후보 수와 시간은 그대로다.
나머지 검토 자료 5,909개도 기존 사유로 계속 제외한다. 원본 음성·라벨과 청취 기능은 보존한다.
[제외 정책](학습준비/자모_원문라벨_3-6세/exclusion-policy.json)과
`exclusions/annotation-tag-excluded.jsonl.gz`에 규칙과 대상 ID를 기록했다.
후속 학습 목록 생성 시 원문 태그와 제외 ID를 확인하며, 청취 메모로 자동 복귀시키지 않는다.

활성 목록은 `dataset-plan.json`의 `active_catalogs`를 따른다.

- 기존 540: `catalogs/AIHUB_540/`의 train/dev/test/review.
- 새 108: **`catalogs_audio_verified/AIHUB_108/`**의 train/dev/test/review.
- `catalogs/AIHUB_108/`, `summary.json`, `validation.json`은 2026-10-26 음성 확보 전 기록으로 보존한다.
- 현재 집계·검증: **`audio-verified-summary.json`, `audio-verified-validation.json`**.

기존 화자 분할은 유지했고 이전 글자 모델의 개발 검증 화자 23명도 학습에 넣지 않았다.
108 공식 Training/Validation에 겹쳤던 녹음자 ID 75개는 어제 정한 하나의 분할을 그대로 유지한다.
사용 가능한 108 후보는 화자·PCM 해시가 분할 사이에 겹치지 않으며 같은 분할 안의 PCM 중복도 제외했다.
기존 540과는 전체 WAV 해시를 비교했다. 서로 다른 데이터셋의 PCM만 비교하거나 실제 인물을 대조한 것은 아니다.

전체 원문·철자·화자·연령·분할을 다시 비교했고 동결 목록·정책·어휘 파일의 해시가 일치했다.
자료에 200시간 상한은 적용하지 않았다. **아직 실행용 학습 manifest와 새 모델은 만들지 않았다.**
다음 단계는 음성 구간 선택·CTC 길이 확인, 69개 출력의 학습 경로 연결과 비교 학습이다.
기존 모델·직접 녹음은 유지했고 D 드라이브에는 접근하지 않았다.

222,604개도 모두 포함된다. 보관 대상 전체를 학습에 넣는다는 의미는 아니며,
기존 검증·테스트 화자는 학습 자료와 계속 분리한다.
원본 라벨 TAR 8개(5.67GB), 전체 색인과 화자 분할, 모델, 직접 녹음, 기존 청취 결과도 보존한다.

**사용자 요청에 따라 원본 음성 TAR 8개, 570,008,140,800바이트(570.01GB)를 삭제했다.**
새로 추출한 4세·U4 음성 3.72GB와 검증 기록 약 1GB를 감안한 전체 정리의 순확보량은
약 565GB다. 삭제 직후 C 드라이브 여유 공간은 약 1.02TB였다. D 드라이브에는 접근하지 않았다.
보관 대상으로 추출하지 않은 음성은 다시 다운로드해야 하며, 전체 색인에 행이 남아 있어도
해당 음성이 로컬에 남아 있다는 뜻은 아니다. 실제 보관 목록은 아래 기록을 따른다.

이전 글자 모델의 학습 목록은 추출된 WAV를 읽으며 필요한 파일이 모두 남아 있다.
사용자는 과거 자모 실험의 모델·기존 결과를 보존하고 원본 TAR 의존 기능은 유지하지 않기로 했다.
따라서 원본 TAR을 직접 읽는 자모 재학습·데이터 재생·일부 청취 자료 생성 명령은 그대로 실행할 수 없다.
기존에 생성한 청취 음성·답변·분석 결과와 모델 파일은 보존했다. 해당 도구를 다시 사용하려면
원본을 다시 확보하거나 추출 WAV를 읽도록 별도로 수정해야 한다.

삭제 후 보관 음성 678,737개의 존재·크기를 다시 확인했다. 모델·실험 기록·녹음·참고자료
46,843개 항목의 크기·수정 시간이 같았고, 주요 모델·기존 학습 목록·색인·화자 분할의
SHA-256도 일치했다. 원본 라벨 TAR 8개는 그대로 남아 있다.

세부 기록은 로컬 `99_Organization/dataset-cleanup-20261026/`에 보관한다.
`plan.json`, `preparation.json`, `preparation-validation.json`은 삭제 전 계획과 검증 기록이며,
실제 삭제는 `deletion.json`, 삭제 후 검증은 `post-deletion-validation.json`이 최종 결과다.
`retain-audio.jsonl`과 `retained-audio.sqlite3`에는 보관 파일·과거 원본 위치·검증 해시가 있다.
삭제 및 원본 대조 스크립트는 완료 기록용이며 다시 실행하지 않는다. 재학습은 실행하지 않았다.

## U4 자료 확인 결과

원본 라벨 871개와 보관 음성을 모두 확인했다. 화자는 9명이며 약 1.12시간, 129.64MB다.
모두 정형 발화이고, `치즈 케이크`, `엄마가 와요`, `책을 펴요` 같은 단어·문장 전사가 있다.
음성 형식은 16kHz·16bit·모노이며 라벨의 품질 표시는 모두 `Good`이다.
이는 라벨과 파일 형식 확인 결과이며, 전체 음성을 사람이 듣고 품질을 판정한 결과는 아니다.

원본 화자 정보는 모두 `Age=U4`, `AgeGroup=G01`, `SchoolYear=Y0`이며 구체적인 나이 숫자는 없다.
[AIHub 공개 설명](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=540)은 나이·연령층 항목을
소개하지만 U4의 정확한 범위는 제시하지 않는다. 연결된 설명서와 구축 가이드도 재확인 시
AIHub 오류 페이지로 연결돼 코드 정의를 확인하지 못했다.

전체 나이 값이 `U4`, `4`~`12`, `O12`로 구성된 점에서는 `U4=Under 4(4세 미만)`라는
해석이 가능하지만 이는 코드 배열에 근거한 추정이며, 공식 정의 확인 결과가 아니다.
제작사 미디어젠의 [2021-09-29 모집 보도자료](https://www.newswire.co.kr/newsRead.php?no=931230)는
대상을 만 4세 이상 미취학 아동부터 초등학교 6학년까지로 안내했다. 모집 기준만으로 실제
U4 자료의 연령을 판정할 수 없으며, U4를 3세 자료라고 확정해서 집계하지 않는다.
공식 정의와 만 나이 적용 여부는 원본 코드 설명서 또는 데이터 제공처의 확인이 필요하다.

3세 대상에 활용할 가능성을 배제할 수 없고 용량이 작아 `audio/U4/`에 따로 보관하기로 했다.
기존 학습 목록에는 넣지 않았다. 정확한 연령과 적합성을 확인한 뒤 다음 학습 포함 여부를 정한다.
원본 라벨 대조와 화자별 집계는 `u4-original-labels.json`, `u4-investigation.json`에 있다.
코드 의미에 대한 추가 확인과 공식 링크 조회 결과는 `u4-code-research.json`에 기록했다.

## 단어 매칭을 위한 자료 사용 기준

2026-10-26 사용자가 확인한 최종 목표는 **아동의 한 단어 발화가 제시된 정답 단어에
충분히 가까우면 통과시키는 것**이다. 정답 `책`에 대해 `짹`에 가까운 발화를 `책`으로
인식하는 것은 허용한다. 표준 단어 라벨로 발음 변이를 같은 단어에 연결하는 학습을
이 목적에 활용할 수 있다. 다만 모든 원본 음성·라벨 쌍의 적합성이 검증된 것은 아니다.

다음은 기대 판정의 예시이며 현재 모델의 실측 결과가 아니다.

| 제시한 정답 | 입력 발화 | 기대 판정 |
|---|---|---|
| 책 | 책 | 통과 |
| 책 | 짹에 가까운 발화 | 통과: 사용자 허용 예시 |
| 책 | 사과처럼 정답과 무관한 말 | 거절 |
| 책 | 무음·환경 잡음 | 거절 |

허용 범위의 경계에 있는 발화는 실제 녹음을 듣고 평가 기준을 정한다. 발음이 다르다는
이유만으로 모든 자료를 오답으로 지정하지 않는다. 실제로 무관한 말을 했거나 말소리가
없는데 목표 단어가 라벨로 붙은 자료는 학습 자료 점검에서 구분한다.

학습에는 적합한 음성·표준 전사 쌍을 사용하고, 제품 평가에는 제시 단어·녹음·기대 통과
여부를 함께 기록한다. 평가는 학습과 화자가 겹치지 않는 3~6세의 한 단어 발화에서
허용 발화 통과율과 무관 발화·무음·잡음 오통과율을 연령별로 확인한다. 전체 전사 정확도는
보조 지표로 사용한다. 실제 발음의 정밀 전사나 오류 진단 라벨은 이 목표의 필수 조건이 아니다.
