목표는 새 기반 모델을 고른 뒤 보유 아동 자료로 파인튜닝하여 사용하는 것이다. 이번에는 두 공개 후보에 우리 아동 자료를 학습시키기 전의 출력과, 이미 아동 파인튜닝을 거친 현재 모델을 동일한 녹음으로 비교했다. 한국어 음소 모델은 일부 악기놀이 단어에서 개선됐고 두 후보 모두 별도 아동 발화·문장에서는 현재 모델보다 낮았다. **이는 학습 전 출발 상태 점검이며, 후보의 아동 파인튜닝 후 성능이나 교체 적합성을 판정하는 결과가 아니다.**

이번 수치는 **임계값이나 악기놀이 임시 보정 전의 모델 출력 비교**다. 정답 처리율이나 아동의 실제 발음 오류율로 해석하지 않는다. 정답을 의도한 글자·제공된 전사에서 만든 기준 발음열과 모델 출력의 일치도를 측정했다. 정상 발음에 잘못된 지적을 하는 비율은 전문가의 실제 발음 라벨이 없어 측정하지 않았다.

발음 비교 규칙은 모델 결과를 보기 전에 정했다.

- 현재 모델의 한글 출력과 기준 전사에는 같은 프로젝트 G2P를 적용했다. `샅/삳`, `잡아/자바`는 같은 발음으로 비교된다.
- 한국어 음소 모델은 공개 MFA 기호표를 IPA로 변환했다. 외국인 모델은 조합형 자모의 초성·중성·종성 정보를 유지하고, 호환 자모는 인접 모음을 이용해 위치를 해석했다. 이미 소리인 출력에 철자용 G2P를 다시 적용하지 않았다.
- 외국인 모델의 호환 자모 `ㅇ`은 실제 들리는 /ŋ/로 보존한다. 모델 카드 예시는 무음 초성 ㅇ을 쓰지 않는다. 자모 `강아지`의 /ŋ/가 모음 앞이라고 삭제되지 않는지 점검했다.
- 한국어 음소 모델의 40개 소리 범위에 맞춰 모든 모델과 기준에서 ㅐ/ㅔ를 같은 비교 기호로 묶었다. 이는 모든 화자의 발음이 같다는 주장이 아니다. 이중모음은 활음과 모음으로 나누고 `uEO`는 ㅝ에 해당하는 /w+ʌ/로 맞췄다. 종성 /l/ 뒤 초성 /ɾ/은 양쪽 모두 /ll/로 비교했다.
