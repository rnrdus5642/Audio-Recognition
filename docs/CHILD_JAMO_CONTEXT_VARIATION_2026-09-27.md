# 무음 여백·음량 추가 학습 비교

## 실행 전 고정한 질문

20ms 간격과 기존 가중치를 유지한 채 앞뒤 무음·음량 변형으로 추가 학습하면,
원본만 같은 양만큼 추가 학습한 경우보다 입력 조건에 덜 흔들리고 실제 발음도
더 잘 맞히는가? 출력 일관성만 높아진 결과를 기존 오류의 해결로 간주하지 않는다.

## 실험 조건

- 수정된 학습 목록에서 예측을 보지 않고 4,096개를 선정한다. 약 절반은 단독 단어를
  단어 종류별로 균형 있게 배정한다. 두 조건 모두 같은 음성을 같은 순서로 두 번 학습한다.
- 기존 청취 평가 녹음과 해당 화자는 이번 추가 학습에서 제외한다. 원래 모델의
  기존 학습 음성 6개는 새로운 화자 일반화의 증거로 세지 않는다.
- 두 조건은 같은 원본 모델에서 출발하고 마지막 Transformer 8개 층과 출력층을
  학습한다. 20ms 간격, 정답, 최적화 설정, 배치, 노출 수를 동일하게 둔다.
- 대조군은 원본만 사용한다. 변형군은 절반을 원본으로 두고, 나머지에 무음만,
  음량만, 둘 다를 균등한 확률로 적용한다.
- 앞뒤 무음은 각각 0~1.2초, 음량은 -15~+6dB다. 음량을 높일 때 단일 배율을
  제한해 새 클리핑을 만들지 않는다. 파형 자르기·음높이·속도 변형은 하지 않는다.
- 추가한 무음은 실제 입력 길이에 포함한다. 배치 크기를 맞추는 채움만 마스크로
  제외한다. 두 조건에서 dropout, SpecAugment, layerdrop은 비활성화한다.
- 서로 다른 무작위 시드 92801, 92802로 반복한다. 결과를 보고 개인 음성에 유리한
  중간 체크포인트를 선택하지 않고 각 2회 학습 종료 상태를 비교한다.

## 평가와 판정

1. 기존 검증 1,500개 전체의 전사 기반 자모 오류를 재측정한다.
2. 40개 자모를 포함하도록 예측 없이 고정한 검증 256개를 원본 및 6개 변형 조건에서
   평가한다. 변형은 앞 370ms, 뒤 830ms, 앞뒤 310/670ms, -12dB, +6dB,
   앞뒤 310/670ms와 -9dB 조합이다.
3. 기존 청취 판단 27개에서도 같은 조건을 평가한다. 개인 음성 11개, 기존 학습
   확인 6개, 추가 청취 10개를 구분하며 모호했던 답변은 정답으로 추가하지 않는다.
4. 학습 32개의 같은 변형 평가는 학습 효과 확인용이며 일반화 성적으로 사용하지 않는다.
5. 화자 단위로 묶은 paired bootstrap으로 변형 검증 오류 차이의 불확실성을 추정한다.
   한 녹음의 여섯 변형을 여섯 독립 표본처럼 취급하지 않는다.

다음 조건을 사전에 기록했다: 변형 검증 오류가 원본 모델과 추가 학습 대조군보다
각각 10% 이상 감소, 원본 검증 자모 오류율의 악화가 0.1%p 이하, 개인 원본 음성의
완전 일치가 양쪽보다 적어도 1개 증가, 기존에 맞히던 청취 원본 유지, `쌕`을 `책`으로
바꾸는 치환 방지. 강건성만 좋아진 경우와 원래 오류까지 개선된 경우를 구분한다.
