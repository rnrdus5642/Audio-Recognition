**wav2vec2 교체 가치 검증: 아동 학습 전 원본·성인 음성·복수 입력 조건 — 2026-09-13**

**후속 검증 안내:** 이 문서는 세 모델 비교 당시의 결과를 보존한 기록이다. 이후 64개 체크포인트를 실측해 우선 후보를 Miniijune V2로 수정했다. 현재 모델 선정 판단과 전체 근거는 [최신 비교](WAV2VEC2_KOREAN_MODEL_SELECTION_2026-09-13.md)를 따른다.

**SLPLab 한국어 음소 모델을 우선 후보로 삼아 아동 파인튜닝을 진행할 가치가 있다.** 성인 문장과 짧은 단어에서 기존 원본보다 소리를 잘 보존했다. 다만 깨끗한 Zeroth 문장에서는 기존 원본이 더 정확했고, 연속 문장 속 짧은 정답의 오확정도 남았다. 따라서 이번 결과는 학습 기반 후보 선정의 근거이며, 현재 아동 모델보다 최종 성능이 좋다는 결론은 아니다. 외국인 한국어 발음 체크포인트는 이번 모든 원음 집계에서 출발 성능이 낮아 후순위로 둔다. 아동 학습 후 개선 폭은 세 모델 모두 이번 실험에서 측정하지 않았다.

비교 대상은 [기존 kresnik 원본](https://huggingface.co/kresnik/wav2vec2-large-xlsr-korean), [SLPLab 한국어 음소](https://huggingface.co/slplab/wav2vec2-xls-r-300m_phone-mfa_korean), [SLPLab 외국인 한국어 발음](https://huggingface.co/slplab/wav2vec2-XLSR-300m_KoreanPhonene_spoken_by_foreigners)이다. 세 모델 모두 우리 아동 자료로 파인튜닝하기 전 체크포인트다. 공개 모델이 기존에 학습한 한국어 자료까지 같다는 뜻은 아니다.

**실제 평가 범위**

| 자료 | 원본 녹음 | 화자 | 사용 범위 |
|---|---|---|---|
| Common Voice 17 한국어 test | 208 | 21 | 20~40대라고 자기 기입한 공개 성인 자료 |
| Zeroth-Korean test | 457 | 10 | 일반 읽기 문장 참고용; 개인별 연령 정보 없음 |

원본 녹음은 718개이며, 입력 조건을 합쳐 모델당 3,157회, 총 9,471회 추론했다. 모델당 전체 발화 입력 1,263개·이동 창 1,812개·생성한 비음성 입력 82개다. 같은 녹음의 잡음 변형·이동 창은 독립 녹음이나 새 화자로 세지 않았다. 원본을 자르거나 다시 라벨링하지 않았다.

Common Voice는 공개 [fsicoli 미러](https://huggingface.co/datasets/fsicoli/common_voice_17_0)의 고정 revision에서 MP3와 전사 TSV를 읽었다(CC0 1.0). 전체 test 339개 중 연령이 10대인 33개와 비어 있는 98개를 제외했다. 성인 208개는 20대 151개·30대 27개·40대 30개다. 녹음 품질이나 모델 정답 여부를 보고 선택하지 않았다. 자기 기입 연령이므로 독립적인 연령 검증 자료는 아니다.

Zeroth는 [Zeroth Project/OpenSLR 40](https://openslr.org/40/)의 test 자료를 [kresnik 미러](https://huggingface.co/datasets/kresnik/zeroth_korean)로 읽었다(CC BY 4.0). **기존 원본 모델은 Zeroth 학습·평가 이력이 있어 이 결과에 같은 계열 자료에 익숙한 이점이 포함된다.** 공정한 미지의 성인 자료 하나로 합치지 않고 별도 표로 남겼다. 다른 체크포인트의 전체 사전학습 자료와 평가 음성의 중복 여부는 확인되지 않았다.

**철자가 아니라 발음 기준으로 계산한 결과**

아래 오류율은 전사 문장을 프로젝트 G2P로 바꾼 기준 소리열에 대한 (삽입+삭제+치환)/기준 소리 수다. `샅/삳`, `잡아/자바`처럼 해당 문맥의 발음이 같으면 감점하지 않는다. 모든 모델과 기준에 동일하게 ㅐ/ㅔ 병합·ㄹ 연속 발음 표기 통일을 적용했고, `놔/와`의 ㄴ과 `잡아/작아`의 자음 차이는 남겼다. `놓아/놔`는 단계 정답으로 모두 허용하되 소리열 완전 일치 계산에서는 서로 다르게 센다. **전문가가 실제로 들린 소리를 전사한 PER이나 아동의 실제 발음 오류율은 아니다.**

| 자료 | 기존 원본 ↓ | 한국어 음소 ↓ | 외국인 한국어 발음 ↓ |
|---|---|---|---|
| Common Voice 성인 문장 | 18.6% | 12.4% | 55.3% |
| Zeroth 읽기 문장 | 1.6% | 9.5% | 50.8% |
| 사용자 성인 단어 | 50.0% | 10.7% | 71.4% |
| 악기놀이 단어·연령 미확인 | 53.7% | 26.1% | 62.4% |

Common Voice 성인 문장에서 한국어 음소 모델은 오류 1,914개를 1,276개로 줄였다(기준 소리 10,299개). **18.6% → 12.4%, 6.2%p 감소·약 33% 상대 감소**다. 21명 각각의 오류율이 모두 개선됐다. 화자 단위 5,000회 재표집의 감소량 95% 구간은 약 5.2~7.2%p다. 표본 내부의 안정성을 확인하는 계산이며 한국 성인 전체나 아동 학습 후의 성능 구간은 아니다.

반면 Zeroth 문장은 기존 원본 1.6%, 한국어 음소 9.5%였다. 읽기 문장 전사와 그 전사의 G2P를 맞추는 평가라 기존 음절 ASR의 철자 전사 능력·자료 계열 적합성이 유리하게 작용할 수 있다. 모델별 차이가 모두 실제 청각 오류 때문이라고 단정하지 않는다. 그래도 일반 문장 성능의 회귀 가능성으로 남겨 두고 아동 학습 후에도 재검사해야 한다.

| 전체 발화의 기준 소리열 완전 일치 | 기존 원본 | 한국어 음소 | 외국인 한국어 발음 |
|---|---|---|---|
| Common Voice 성인 문장 | 5/208 (2.4%) | 9/208 (4.3%) | 0/208 (0.0%) |
| Zeroth 읽기 문장 | 322/457 (70.5%) | 6/457 (1.3%) | 0/457 (0.0%) |
| 사용자 성인 단어 | 2/7 (28.6%) | 4/7 (57.1%) | 0/7 (0.0%) |
| 악기놀이 단어·연령 미확인 | 3/46 (6.5%) | 13/46 (28.3%) | 1/46 (2.2%) |

문장은 소리 하나만 달라도 전체 일치에서 탈락하므로 단어 통과율과 비교하지 않는다. 정상적인 발음 변이와 G2P 기준의 차이도 포함될 수 있다.

공개 성인 녹음 `이거 놔! 놓으라고!`에서도 차이가 보였다. 기존 원본은 `이나 오라고`를 출력했고, 한국어 음소 모델은 `I G EO N A N O EU R A G O`를 출력했다. 후자는 ㄴ을 보존했지만 `놔`의 /w/를 빠뜨려 기준 13개 소리 중 1개 오류가 남았다. **출력 기호에 ㄴ·ㅘ가 있다고 해서 놔를 언제나 정확히 듣는 것은 아니다.** 이 예시 하나를 발음 오류 안내의 정답 라벨로 사용하지 않는다.

Common Voice 중 기존 모델 어휘에 없는 철자가 들어간 22개 문장에서는 소리 오류율이 21.7% → 14.5%로 줄었다. 나머지 186개에서도 18.1% → 12.1%로 줄어, 개선이 미지원 철자 포함 문장에만 한정되지는 않았다. 빠진 철자와 실제로 구분할 필요가 있는 소리의 수는 동일하지 않다.

**잡음·무음·입력 길이 검사**

공개 자료의 변형 실험은 추론 전에 각 화자의 원본 SHA256 순으로 최대 2개씩 정한 58개(Common Voice 38·Zeroth 20)를 사용했다. 아래는 같은 Common Voice 38개끼리 비교한 오류율이다.

| 입력 조건·성인 문장 38개 | 기존 원본 ↓ | 한국어 음소 ↓ | 외국인 한국어 발음 ↓ |
|---|---|---|---|
| 원음 | 19.1% | 10.7% | 56.1% |
| 앞뒤 무음 각 1초 | 19.9% | 11.0% | 54.2% |
| 추가 백색잡음 SNR 20dB | 33.5% | 19.0% | 57.5% |
| 추가 백색잡음 SNR 10dB | 59.6% | 34.3% | 66.4% |

잡음 SNR은 원음의 활성 20ms 구간 RMS로 정했고, 모든 모델에 동일 PCM을 넣었다. 실측 실내·악기 소음과 같은 조건은 아니다. 잡음이 커지면 한국어 음소 모델도 분명히 나빠진다.

보유 단어 53개에는 추가로 음량 −12dB, 0.9배·1.1배 재생, 100ms 뒤 0.3배 크기의 인공 반사음을 적용했다. 재생 변형은 속도와 피치가 함께 바뀌며 다른 화자나 아동 목소리를 만든 것이 아니다. 한국어 음소 모델의 사용자 단어 오류율은 원음 10.7%, 작은 음량 10.7%, 인공 반사음 17.9%, SNR 10dB 78.6%였다. 악기놀이 46개에서도 인공 반사음은 26.1% → 49.1%로 악화됐다. 낮은 음량 단독 변화가 작은 것은 표준 전처리의 파형 정규화 영향도 있으므로 실제 작은 목소리·낮은 SNR에도 강하다는 뜻은 아니다.

| 한국어 음소 모델·창 전체가 기준과 연속 2회 일치 | 1.5초 창 | 2.5초 창 | 4.0초 창 |
|---|---|---|---|
| 사용자 성인 단어 | 3/7 (42.9%) | 5/7 (71.4%) | 5/7 (71.4%) |
| 악기놀이 단어·연령 미확인 | 14/46 (30.4%) | 17/46 (37.0%) | 19/46 (41.3%) |

이동 간격은 0.5초이며 파일 시작 전에는 0을 채웠다. 짧은 단어에서도 1.5초 창으로 줄이면 연속 일치가 끊길 수 있다. 4초가 모든 자료에서 최적인 것은 아니고, 여기서는 보유 단어의 연속 일치가 개선됐다. 같은 발화가 겹친 창에 계속 들어오는 것이므로 연속 2회는 아동이 두 번 독립적으로 말한 검사와 다르다.

**같은 정답 판정기를 연결했을 때의 통과·오확정**

세 모델 모두 현재 저장소의 `ko_child_v2`와 `Matcher.for_streaming`을 동일하게 연결한 오프라인 진단이다. 이 행렬은 원래 아동용이므로 성인·신규 모델에 최적화됐다고 보지 않는다. `skip_cost=0.005`, `coverage=0.8`, `context_mult=8`을 재사용했다. 비교를 위해 임계값 0.70/0.80/0.85/0.90/0.95/1.00, 연속 1/2/3회, 보유 음성 창 1.5/2.5/4초를 모두 집계했다. 모델별로 점수를 보고 유리한 설정을 고르지 않았으며 운영 설정은 변경하지 않았다.

다음은 고정 예시 **임계값 0.90·2.5초 창·연속 2회**다. 원래 악기놀이 9단계의 정답 목록을 사용해 각 녹음을 각 단계에서 시험했다. `잡아`가 세 단계에 쓰이므로 같은 녹음이 세 정답 상황에 들어간다. 분모는 녹음 수가 아니라 **녹음×단계 상황 수**이며 독립 사건 수가 아니다. 정답 목록은 [집계 JSON](data/wav2vec2-broad-comparison-2026-09-13.json)의 `matching_policy.stages`에 고정했다.

|---|---|---|---|
| 사용자 성인 단어 | 0/15 (0.0%) | 12/15 (80.0%) | 0/15 (0.0%) |

| 오답 상황의 잘못된 통과 | 기존 원본 | 한국어 음소 | 외국인 한국어 발음 |
|---|---|---|---|
| 사용자 성인 단어 | 0/48 (0.0%) | 0/48 (0.0%) | 0/48 (0.0%) |
| 악기놀이 단어·연령 미확인 | 0/308 (0.0%) | 0/308 (0.0%) | 0/308 (0.0%) |

성인 공개 문장 대조는 38개에 9단계를 대입하되, 기준 발음열 안에 그 단계 정답의 소리열이 실제로 들어 있는 상황은 제외했다. 남은 304상황에서 원본은 1개 녹음·3상황(1.0%), 한국어 음소는 2개 녹음·6상황(2.0%)이 잘못 통과했다. 두 개 녹음의 반복 집계이므로 실사용 오확정률이 정확히 1%p 증가한다고 일반화하지 않는다. 완성 발음열이 아니라 어절 의미나 사용 의도를 판정하는 정책도 측정하지 않았다.

한국어 음소 모델은 `들여다볼` 일부를 `들어`의 소리열로, `적시었다` 일부를 `쳐`의 소리열로 출력해 매칭했다. 모델 출력에서 실제 정답 소리열이 생기면 임계값을 0.95로 높여도 이 6상황이 남았다. 이는 소리 인식과 부분 문자열 매칭이 함께 만든 실패다. 정답 후보를 늘리거나 연속 횟수만 조절하면 항상 해결된다는 가정은 맞지 않았다.

|---|---|---|---|
| 악기놀이 정답 상황 통과 | 70/106 (66.0%) | 66/106 (62.3%) | 52/106 (49.1%) |
| 악기놀이 오답 상황 오확정 | 3/308 (1.0%) | 0/308 (0.0%) | 0/308 (0.0%) |
| Common Voice 오답 상황 오확정 | 12/304 (3.9%) | 6/304 (2.0%) | 6/304 (2.0%) |

연속 2회는 보유 단어에서 잠깐 발생한 오확정을 줄였지만, 3회로 늘리면 정답 통과가 추가로 줄면서 공개 문장 오확정은 그대로였다. 겹친 입력 창에 같은 오인식이 지속될 수 있기 때문이다. 모든 임계값·창·연속 횟수 결과는 집계 JSON의 `matching_sweep`에 있다. 별도 검증 세트에서 선택한 최적 운영 임계값을 제시한 결과는 아니다.

생성한 무음·백색잡음·저주파 잡음·단일 주파수·클릭 82개에서는 임계값 0.90에서 세 모델 모두 단일 입력의 정답 점수 초과가 0개였다. 다만 일부 입력에 비어 있지 않은 소리를 출력했으며, 한국어 음소 모델도 5초 무음에서 소리를 하나 출력했다. 이 검사는 생성한 신호를 한 번씩 입력한 것으로 실제 악기 소음의 오확정률·VAD·연속 확정 상태를 검증한 것은 아니다.

**처리 비용과 남은 개발 작업**

RTX 5060 Ti, FP32, batch 1, CUDA에서 2.5초 창 1,234개/모델을 측정했다. 처리 시간은 전처리·추론·디코딩·소리 변환을 포함하고 파일 읽기·VAD·렌더링·사용자 확정 대기는 제외한다. 메모리는 실행 전체에서의 PyTorch 할당 최댓값이며 장치 전체 점유량이 아니다. 세 모델 모두 약 315M 계열이라 이번 Python GPU 처리비는 비슷했다. **Unity/Sentis의 시간·메모리·출력 호환성은 아직 측정하지 않았다.**

현재 우선순위는 한국어 음소 모델의 아동 파인튜닝이다. 학습 때는 현재 모델과 동일한 아동 화자 분할을 유지하고, 같은 평가 음성을 보고 반복해서 설정을 맞추지 않는다. 검증 세트에서 임계값을 고른 뒤 별도 평가 세트에서 같은 허용 오확정 수준의 정답 통과율을 비교해야 한다. 짧은 단어만 좋아지고 기존에 잘 되던 단어·문장이 나빠지지 않는지도 포함한다.

개발 범위는 음소 라벨 생성·범위 검사, Python/C#의 MFA→프로젝트 소리 변환, CTC blank·토큰 매핑·ONNX 내보내기, Unity 입력 길이와 확정 동작 검증이다. 공개 모델은 완성형 글자를 출력하지 않으므로 모델 파일만 바꿔 넣을 수는 없다. 현재 아동 음성 처리부에 새 자모·음소 출력층을 학습시키는 방안도 학습 비교의 후보로 남긴다. 원시 XLS-R 1B는 이번 추론 대상이 아니며 크기만으로 우열을 판단하지 않는다.

발음 오류 안내는 별도 과제다. 기준 문장을 기계적으로 음소로 바꾼 학습 라벨에는 아동이 실제로 다르게 낸 발음이 자동으로 기록되지 않는다. 정상 발음을 잘못 지적하는 비율과 실제 차이를 놓치는 비율은 사람이 확인한 실제 발음 라벨로 측정해야 한다. **이번 12.4%를 발음 지적 오확정률로 사용하지 않는다.** 실제 `와` 단독 대조도 이번 자료에는 없어 `놔/와` 구분 전체를 검증했다고 말할 수 없다.

**재현·검증 기록**

모델별 가중치 로딩 누락·예상 밖·크기 불일치가 없었고, 모든 입력의 PCM SHA256을 모델 간에 확인했다. 전처리기는 각 체크포인트의 표준 설정을 사용했으며, MP3·parquet 안의 음성을 동일하게 16kHz 모노로 변환했다. greedy CTC를 사용하고 언어모델·발표용 별칭·정답별 모델 출력 보정은 적용하지 않았다. 기호 변환은 앞선 성인 비교의 고정 함수를 그대로 재사용해 평가 결과에 맞춰 바꾸지 않았다. 학습·운영 임계값 변경·Unity 수정·패키지 교체는 수행하지 않았다.
