# 기존 무음 여백까지 조절하는 추가 학습

## 입력 분포에서 확인한 문제

앞선 실험은 기존 녹음에 무음을 더했다. 선정한 학습 4,096개를 다시 검사하니
2,831개에는 앞뒤 합계 100ms 이상의 정확히 0인 여백이 있었다. 파일 길이가
1.5초 미만인 것은 5개였지만, 양끝의 정확한 0만 제거하면 474개,
80ms 이상 여백과 20ms 합성곱 위상을 보존하면 379개였다.

4,096개 모두 원본 WAV가 모노였고, 학습 파형은 원본 디코딩 파형의 직접 슬라이스와
완전히 같았다. 따라서 확인된 여백은 이번 전처리가 생성한 것이 아니다.
원본 데이터가 만들어질 때 여백을 붙인 경위까지 확인한 것은 아니며,
이 분포 차이가 개인 음성 오류의 원인이라고 확정하지 않는다.

## 학습 전에 고정한 후속 조건

- 이전 실험과 같은 4,096개, 같은 두 시드, 같은 순서, 같은 2회 학습을 사용한다.
  마지막 8개 층과 출력층, 학습률, 배치, 20ms 간격, 정답은 동일하다.
- 절반은 원본 그대로 둔다. 나머지는 정확히 0인 양끝 여백만 줄이고,
  가능한 경우 각 끝에 80~100ms를 남긴다. 제거량은 20ms의 배수다.
  내부 무음 및 0이 아닌 모든 샘플을 보존한다.
- 변형 절반 안에서 음량, 여백, 둘 다를 균등하게 배정한다. 여백은 추가 없음,
  양끝 각각 0~120ms, 양끝 각각 0~1.2초를 균등하게 배정한다.
  음량 범위는 -15~+6dB이며 새 클리핑을 만들지 않는다.
- 변형한 길이가 원래 CTC 정답을 수용하지 못하면 원본 여백을 유지한다.
  정답을 자르거나 음성 구간을 잘라 맞추지 않는다.
- 완료된 동일 시드 원본 추가 학습을 대조군으로 재사용한다. 초기 가중치,
  데이터, 최적화 설정을 확인하고 실제 전체 업데이트·음성 순서까지 대조한다.
- 검증 1,500개, 고정 256개×7조건, 청취 27개×7조건 및 사전 판정은
  [앞선 실험](CHILD_JAMO_CONTEXT_VARIATION_2026-09-27.md) 그대로 유지한다.
- 별도 보조 검사로 동일 검증 256개 및 청취 27개의 기존 0 여백을 안전하게 줄여,
  원본/원본 추가 학습/무음 추가만 학습/기존 여백 조절 학습 모델을 비교한다.
  사전 판정 조건을 대체하거나 유리한 체크포인트를 고르는 데 쓰지 않는다.

첫 시드의 실제 8,192회 입력을 학습 전 전수 검사했다. 0 여백을 줄인 노출은
2,819회, 1.5초 미만 입력은 원본 10회에서 변형 후 295회였다.
0이 아닌 샘플 제거와 CTC 길이 부족은 모두 0회였다.

두 번째 시드에서는 0 여백 조절 2,875회, 짧은 입력 292회였고 신호 제거와
CTC 길이 부족은 역시 0회였다. 짧은 입력의 고유 녹음은 각각 234개·233개,
화자는 103명·104명이었다. 전체 학습에는 40개 자모가 모두 있지만 첫 시드의
짧은 입력에는 `ㅒ·ㅞ·ㅢ`가 없었다. 이 실험을 모든 자모의 짧은 발음에 대한
충분한 학습으로 해석하지 않는다.
[입력 분포·신호 보존 전수 검사](data/child-jamo-context-input-audit-20260927.json)

원본 파일과 서비스 모델은 변경하지 않는다. 실행 기록은
`.venv/hubert-child-20260914/context-span-20260927/`에 있다.
실행 코드는 `context_span.py`, 변형 코드는 `context_span_augmentation.py`다.
신호 보존·CTC 길이·기존 평가 동일성 검사 4개를 통과했다.

두 반복과 기존 0 여백 제거 보조 검사까지 완료했다.
