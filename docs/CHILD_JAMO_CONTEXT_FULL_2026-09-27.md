# 문맥 처리층 전체를 학습하는 무음·음량 비교

**상태: 준비만 완료했고 실행하지 않았다.** 학습 입력의 긴 0 여백을 확인한 뒤
[기존 여백 조절 실험](CHILD_JAMO_CONTEXT_SPAN_2026-09-27.md)을 우선 실행했고 평가까지 완료했다.
[추가 학습 판정](CHILD_JAMO_CONTEXT_CONCLUSION_2026-09-27.md)에서 변형의 이점을 확인하지 못했으며,
이 전층 실험은 보류 상태로 남아 있다. 아래는 실행하지 않은 계획이다.
현재 우선순위는 [작업 현황](CHILD_JAMO_STATUS.md)을 따른다.

앞선 마지막 8개 층 비교는 앞쪽 40개 층과 위치 정보를 처리하는 합성곱을 동결했다.
문맥 민감성이 계산 과정에서 확인됐던 부분까지 학습을 허용하여, 그 제약 때문에
변형 효과를 배우지 못했을 가능성을 추가 검사한다.

## 실행 전 고정한 조건

- 같은 4,096개, 같은 청취 평가 제외 규칙, 같은 2회 학습, 같은 원본/무음·음량
  변형 대조를 사용한다. 입력 20ms 간격과 라벨은 바꾸지 않는다.
- 48개 Transformer 층, 위치 합성곱, 특징 투영, 출력층을 학습한다. 파형 합성곱
  앞단만 기존 본학습과 동일하게 동결한다.
- GPU 메모리 범위 안에서 실행하도록 48개 Transformer 층의 AdamW 상태를 CPU에
  둔다. 원래 본학습에서 사용한 동일 최적화 구현을 사용한다.
- 두 조건 모두 16개 미니배치마다 업데이트한다. 마지막 8개 층 비교보다 누적
  배치가 크므로, 두 실험 사이 차이를 학습 범위 하나의 효과로 단정하지 않는다.
  이 실험 안에서 원본 추가 학습과 변형 추가 학습의 차이를 비교한다.
- 인코더 학습률 1e-5, 출력층 5e-5, 16회 준비 구간 뒤 cosine 감소,
  무작위 시드 92801, 고정된 2회 학습 종료 모델을 평가한다.
- 위치 합성곱, 첫 층, 마지막 층, 출력층에 유한한 0이 아닌 gradient가 발생하고
  실제 가중치가 바뀌었는지 검사한다. 학습 설정 표시만으로 범위 변경을 주장하지 않는다.
- 검증 음성 및 사전 판정 기준은 [8개 층 실험](CHILD_JAMO_CONTEXT_VARIATION_2026-09-27.md)과 같다.
  한 시드의 탐색적 범위 확대이며, 새 독립 평가 자료로 취급하지 않는다.

실행 코드: `python/tools/child_jamo_finetune/context_full.py`.
