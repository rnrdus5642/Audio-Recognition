로컬 패키지 **0.8.4**, 프로필 **music_demo_2026_09_10**. 최초 배포 당시 Git 커밋·원격 게시 없이 적용한 발표용 수정이다.

## 확인한 원인과 수정

- `실로폰채를 쳐`는 올바른 음소를 넣어도 기존 전체 발화 조건에서 탈락했다. 특정 악기 이름이 동작 앞에 오는 경우를 등록하고, 접두 표현과 동작의 음소 구간이 겹치지 않는지 검사한다. 접두 표현은 0.80 이상으로 일치해야 한다. 이후 동작 부분으로 전체 점수와 다른 동작을 비교한다. 악기 이름의 길이로 잘못 말한 동작의 점수가 올라가는 방식을 피한다.
- `잡아`는 연속 판정 3회에서 2회로 줄인다. 한 번 말한 소리를 0.5초 간격의 여러 창에서 확인하는 횟수다.
- `잡아·때려·연주해·내려놔`에 짧은 발화 전용 보완 조건을 추가한다. 일반 문장 판정과 별도로 음소 길이, 정답 단어 전체 점수, 부분 점수를 모두 검사한다. 다른 동작 비교와 연속 판정은 그대로 거친다.
- Unity에 `OnFrameScoredDetailed`, `LastFrameScored`, 최근 120프레임과 명시적 로컬 JSON 저장을 추가한다. 모델이 무엇으로 인식했는지, 음량이 작은지, 점수·전체 발화·다른 동작·연속 횟수 중 무엇 때문에 탈락했는지 확인할 수 있다.

아동 모델의 재학습·교체는 하지 않았다. 기존 `발음에 문제 없어요.` 표시와 모델 혼동에 대한 내부 보류, 원본 발음 비교도 유지한다.

## 동일 녹음의 변경 전후 비교

보유 아동 음성 775개, 합성 음성 24개, 참조 음성 4,998개의 **기존 실제 모델 출력**을 동일하게 재생해 비교했다. 임계값 조정에 사용한 자료이며 독립 평가 세트나 아동·성인 간 성능 비교가 아니다. 문장 녹음을 단어 단위로 새로 자르지 않았다.

| 표현 | 아동 발화 확정 0.8.3 → 0.8.4 | 합성 단어 확정 | 참조 오확정 / 비교 발화 수 |
|---|---|---|---|
| 잡아 | 65 → 68 / 77 | 0 → 0 / 2 | 0 → 1 / 4,995 |
| 쳐 | 4 → 4 / 111 | 2 → 2 / 2 | 6 → 3 / 4,986 |
| 때려 | 1 → 7 / 64 | 1 → 2 / 2 | 0 → 3 / 4,994 |
| 연주해 | 23 → 24 / 33 | 1 → 2 / 2 | 0 → 1 / 4,996 |
| 내려놔 | 0 → 1 / 1 | 2 → 2 / 2 | 0 → 5 / 4,950 |

아동 자료는 잡아·때려·연주해가 문장 발화, 내려놔가 단일 `내려놔요`, 쳐가 문장 104개 + 단일 7개다. 해당 표현이 없는 아동 자료에서도 오확정이 남는다: 잡아 13→14/698, 때려 0→2/599, 내려놔 0→2/621. 분모는 해당 정답·동작과 관련된 표현을 제외하고 산정했다.

12단어 및 9단계 검사 모두 기존 정답 확정의 손실은 없었다. 단계 1·4·8의 잡아 관련 아동 확정은 각각 3개 증가했고, 단계 2는 7개, 단계 5는 6개, 단계 9는 5개, 단계 3·7은 각각 1개 증가했다. 단계별 숫자는 같은 녹음을 재사용하므로 합쳐서 독립 발화 수로 해석하면 안 된다.

별도의 올바른 음소 입력 검사에서는 등록 접두 표현 + 5개 동작의 기본형·요 형태가 적용 단계에서 모두 확정된다. `실로폰채`만 발화하거나 `실로폰채를 들어`라고 말해 단계 2의 치기를 통과하는 경우는 차단한다. 음소 입력 검사는 문장 판정 로직 검사이며 마이크 인식률 측정이 아니다.

## 남는 한계와 다음 현장 검사

- `잡아`를 모델이 `서랍`으로 인식한 합성 음성은 여전히 실패한다. 서랍까지 잡아로 받아들이는 대응은 적용하지 않았다.
- 모델은 아동 자료로 미세조정되어 있다. 성인 목소리, 마이크·거리·음량의 영향은 가능하지만 이번 사용자의 실패 음성·로그가 없어 원인을 확정할 수 없다. 아동에게서는 잘된다는 결론도 낼 수 없다.
- 일부 오확정이 증가한 발표용 절충이다. 임의의 문장 의미, 부정 명령, 배경 대화까지 이해하거나 차단하는 기능은 아니다. 사용자의 실제 성인 체험 음성과 새 아동 음성으로 추가 현장 확인이 필요하다.
- 기존 바탕화면 9월 9일 오디오 정리표는 당시 검사 기록이다. 이미 통과한 예시는 이번 재검사에서도 유지됐다.

새 패키지 설치 후 문제 표현을 한 번씩 평소 음량으로 말하고, 실패하면 재시도 전에 Listener의 `Save recognition diagnostics / 인식 진단 저장` 메뉴로 JSON을 저장한다. 경로는 Console에 표시된다. 저장 파일에는 원본 음성이 없으므로 청취 비교가 필요하면 음성은 별도로 보관해야 한다.
