# 괄호 표기 후보 8개 청취 결과와 다음 단계

**청취로 구분한 발음을 모델이 바깥 표기의 단어로 출력하는 사례가 2개 더 나왔다.**
반면 괄호 안 표기를 모든 음성의 정답으로 채택할 수는 없다. 명확한 선택은 3개이고,
비교 학습에서 라벨이 달라질 후보는 학습용 1개·검증용 1개뿐이다. 이 상태에서 학습을
반복하면 한 사례를 외운 효과와 일반적인 발음 구별 개선을 구분하기 어렵다.

## 실제 답변과 모델 대조

8개 모두 응답했고, 수정 이력을 포함한 9개 기록을 보존했다. 마지막 응답 기준으로
해석한다. 자유 입력과 메모는 전부 비어 있다. 이전의 ‘한글로 적은 내용이 정밀한 발음
표기는 아닐 수 있다’는 설명을 계속 적용한다.

| 구분 | 개수 | 처리 |
|---|---:|---|
| 괄호 안 표기로만 들림 | 2 | 해당 선택을 실제 발음 라벨 후보로 보존 |
| 괄호 밖 표기로만 들림 | 1 | 전사와 같은 라벨의 대조 후보 |
| 둘 다 가능 | 3 | 어느 쪽도 단독 정답으로 채택하지 않음 |
| 둘 다 아님 | 2 | 정확한 대체 발음 미확정으로 보류 |

| 번호 | 미리 정한 용도 | 제공 표기 | 사용자 선택 | 기존 모델 출력 |
|---|---|---|---|---|
| 1 | 학습 후보 | 싸워요(사워요) | 사워요 | 싸워요 |
| 2 | 학습 후보 | 아저씨(아저찌) | 아저씨 | 아저씨 |
| 5 | 검증 후보 | 원숭이(웡숭이) | 웡숭이 | 원숭이 |

3번 풍선/푼선, 4번 우주선/우두선, 6번 크레용/크에용은 둘 다 가능이다.
7번 싱글벙글/싱글벙그, 8번 친구/치구는 둘 다 아님이다. 모델이 이 두 문항에
`싱급ㅇ그`, `키쿠`를 출력했지만, 그 출력이 맞다고 사용자가 확인한 적은 없다.
이를 대체 정답으로 쓰거나 모호한 문항까지 추가 오류로 세지 않는다.

모델 대조는 응답 후 원래 체크포인트로 시행했고 선택·청취 화면에 예측을 사용하지
않았다. 모델 가중치는 바꾸지 않았다. `사워요`, `웡숭이`의 CTC 전체열 점수는 각각
바깥 표기보다 낮았지만, 이 점수는 모델의 선호이며 실제 발음일 확률이 아니다.

## 원인에 대해 말할 수 있는 범위

- 8개 원본 JSON·WAV·실제 재생 PCM·답변 binding을 다시 검증했다. 원본 전체 PCM을
  사용했으므로 이번 청취 차이를 우리 구간 자르기나 음높이·속도 변환으로 설명하지 않는다.
- 8개 모두 기존 학습·검증·테스트 목록에 없는 자료다. 따라서 이 8개의 잘못된 정답이
  기존 모델에 들어갔다고 해석하면 안 된다. 원본에는 괄호 표기가 있었고 현재 전처리는
  해석하지 않고 파일을 제외했다.
- 사용자 선택과 모델 출력을 기준으로, 실제 발음 차이를 전사와 같은 단어로 출력하는
  현상이 서로 다른 두 화자에서 관찰됐다. 발음 차이를 보존하는 정답을 따로 확보해
  학습 효과를 비교할 이유가 늘었다.
- 이 결과만으로 학습 라벨이 원래 `책 → 샙`, `나비 → 나리`의 주원인이라고 확정하지
  않는다. 두 유형은 반대 방향의 오류일 수도 있으며, 같은 비교 실험에서 함께 평가한다.
- 작은 괄호 표본의 비율로 전체 데이터 오류율을 계산하지 않는다. 괄호 안을 일괄 사용하거나
  정상 단어로만 치환하는 규칙은 추가하지 않았다.

## 추가 12개 준비 당시의 계획

단독 선택 3개는 원본·재생 해시, 화자 분할, 답변 revision과 함께 별도 후보로 저장했다.
선택 문구를 그대로 자모로 분해했으며 다시 G2P를 적용하지 않았다. 이는 한 사람의 단어
선택을 저장한 **조건부 후보**이고 전문가 음성 전사나 실행용 학습 목록은 아니다.

추가 확인은 **새 화자 12명, 12개 음성, 총 43.584초**로 제한했다. 기존 8개 화자는
제외하고 학습 후보 6명·검증 후보 6명을 기존 분할대로 유지한다. 괄호 쌍의 음절 수가
같고 초성·중성·종성 문자 성분이 1~2개 다른 단독 단어를 고정 해시 순서로 골랐다.
첫 묶음과 달리 모음 차이도 포함한다. `주스/쥬스` 표기 쌍은 이번 선정에서 제외했다.
이 조건은 선택지의 문자 구조를 제한하는 것이며, 실제 소리가 명확하다고 보장하지 않는다.

선정·A/B 배치는 새 음성을 열기 전에 고정했다. 준비 시점에는 새 12개의 모델 추론을 시행하지
않았으며, 이전처럼 ‘둘 다 가능’과 ‘둘 다 아님’을 구분한다. 페이지는 별도 DB를 사용한다.

**완료 답변 확인 주소: http://127.0.0.1:8775/**

12개 답변 후 라벨이 실제로 다른 학습·평가 사례와 화자 수를 다시 집계한다. 사용할 수
있는 자료가 확보되면 같은 음성·동일한 학습 설정에서 라벨만 다른 비교로 진행한다.
확정 가능한 사례가 계속 적으면 자동으로 청취 묶음을 늘리지 않고, 현재 표기 기반
검수 방식의 한계와 발음 주석 확보 방식을 재검토한다. 준비 시점에는 새 재학습을 시작하지 않았다.

## 이후 완료 결과

추가 12개도 모두 응답을 받았다. 두 묶음을 합쳐 학습 6개·다른 화자 검증 4개의
단독 선택을 얻었고, 미확정 10개는 보류했다. 두 조건의 72회 업데이트 비교도 완료했다.
청취 라벨 조건은 학습 일치가 3/6에서 4/6으로 늘었지만 검증과 원래 오류는 개선하지
못했으며, `쌕→책` 오판으로 후보를 채택하지 않았다. 추가 청취와 실행 중인 학습은 없다.
