발표 범위는 사용자 이미지의 **9단계, 고유 정답 12개**다. 현재 구현과 설정표는 [단어별 조정 결과](MUSIC_WORD_TUNING_2026-09-07.md)에 정리했다.

사용자 요청에 따라 사전 녹음을 등록해 비교하는 방안은 채택하지 않았다. 기존 음소 인식 엔진의 단어별 임계값, 연속 검사 횟수, 전체 발음 검사 조건을 조정했다. 새로 받는 아동 음성은 기능 평가와 발표 영상에 사용한다.

발표 구성은 다음과 같다.

- 체험: `start_music_demo.ps1` 실행 → 9단계 중 선택 → 준비 → 마이크로 정답 발화.
- 아동 음성 영상: 같은 화면에 녹음 파일을 올리고 파일 테스트로 검사 과정과 결과 확인.
- 결과 설명: 기존 아동 정답 녹음 3/13 → 9/13, 합성 음성 16/24 → 22/24. 조정에 사용한 자료의 수치이며 새 아동의 성공률은 아니다.

`실로폰채·놓아·탬버린·북채·때려`는 실제 아동 음성 확인이 남아 있다. `놔/와` 오확정 사례도 남아 있으므로 모든 발화가 안정적으로 통과한다고 설명하지 않는다. 상세 실패 사례와 오확정 수는 위 결과 문서에서 확인한다.

9/12 발표 전에는 9/11까지 실제 발표 마이크로 9단계를 점검하고, 사용하려는 아동 파일의 성공·실패를 확인한 뒤 촬영한다. 마지막에 검사한 설정 파일과 모델을 같은 상태로 유지한다.

[MUSIC_PRESENTATION_RECORDING_SHEET.csv](MUSIC_PRESENTATION_RECORDING_SHEET.csv)는 추가 평가 파일과 결과를 적는 선택 사항이다. 기준 음성 등록표가 아니며, 빈 상태여도 체험 기능은 실행된다.
