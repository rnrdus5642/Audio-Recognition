# 원본 모델과 아동 파인튜닝 모델의 동일 녹음 비교 · 2026-09-12

현재의 오인식을 아동 파인튜닝 때문에 새로 생긴 문제로 묶을 근거는 없다.
제공된 녹음에서는 원본부터 실패하는 경우가 많았고, 아동 모델이 전체적으로 개선됐다.
다만 일부 단어와 입력 창은 아동 모델에서 나빠졌다. 이 비교로 wav2vec2 계열 전체의
성능이나 모든 성인·아동의 인식률을 판단하지 않는다.

## 비교 대상과 조건

- 원본: `kresnik/wav2vec2-large-xlsr-korean`, 로컬 캐시 revision
  `629c9a3501c10ba128bf3fa1eebb12af3be03f61`.
- 아동: `python/tools/child_finetune/runs/child/best`, step 27,000.
- 두 화자 악기놀이 녹음 46개와 이전 사용자 잡아 5개·작아 2개, 합계 53개.
- 두 화자의 나이를 새로 확인하지 않았다. 사용자 녹음 묶음과 두 화자가 독립된 세 명이라고
  가정하지 않는다. 라벨은 의도한 단어이며 전문가가 판정한 실제 발음 라벨이 아니다.
- 같은 16kHz 모노 WAV를 양쪽에 입력했다. 원본·분할 파일을 수정하지 않았다.
- 파일 전체 입력과, 이전에 검증한 동일 2.5초 창·0.5초 hop·시작 지연 0의 입력을 따로 비교했다.
  파일 전체 입력에는 외부 무음 패딩을 추가하지 않았다. 창 입력은 기존 재생 꼬리 구간까지 사용했다.
- 모델별 파일 전체 53회 + 같은 PCM 창 289회, 총 **684회 실제 GPU 추론**.
- 두 모델 모두 float32와 같은 런타임 전처리·CTC 디코딩·G2P를 사용했다.
  유효 오디오 전처리 설정과 출력 가능한 1,205개 토큰의 번호가 일치함을 확인했다.
- 정답 매칭, 임계값, 연속 확정 정책과 발표용 보완은 적용하지 않았다. 모델이나 패키지를 바꾸거나
  추가 학습하지 않았다. 복원된 0.7.0 작업 기준도 유지했다.

원본 모델의 공개 자료는 [모델 카드](https://huggingface.co/kresnik/wav2vec2-large-xlsr-korean)를 따른다.
그 카드의 Zeroth-Korean 성능은 해당 평가 조건의 수치이며 이번 단어 녹음에 그대로 적용하지 않는다.

## 결과

여기서 정확한 전사는 **공백을 제거한 전체 출력 글자가 라벨과 같은 경우**다.
음소 유사도나 같은 동작 표현을 허용한 게임 정답률과 다르다. 예를 들어 `놓아 → 노아`도
글자 불일치로 센다. 창 중 한 번 맞았다는 것과 실제 세션에서 정답으로 확정했다는 것도 다르다.

| 측정 | 원본 | 아동 모델 |
|---|---:|---:|
| 53개 파일 전체 입력에서 정확한 전사 | 3/53 | 14/53 |
| 위 문자 편집거리 합 / 라벨 글자 수 | 78/110 · 70.91% | 52/110 · 47.27% |
| 2.5초 창 중 정확한 전사가 한 번 이상 나온 녹음 | 5/53 | 12/53 |
| 정확한 전사가 두 창 연속 나온 녹음 | 2/53 | 10/53 |
| 두 화자 46개 · 파일 전체 정확한 전사 | 3/46 | 12/46 |
| 이전 사용자 잡아 5개 · 파일 전체 정확한 전사 | 0/5 | 0/5 |
| 이전 사용자 작아 2개 · 파일 전체 정확한 전사 | 0/2 | 2/2 |

파일 전체 입력에서 두 모델 모두 맞은 것은 3개, 아동만 맞은 것은 11개,
원본만 맞은 것은 0개, 둘 다 글자 전체를 맞추지 못한 것은 39개다.
이 지표가 개선됐어도 개별 녹음의 편집거리나 창별 인식이 모두 좋아졌다는 뜻은 아니다.

## 개선된 사례와 남은 실패

동일 파일 전체를 입력한 예시다. 아래 전사는 모델 출력이며 실제 발음을 단정하지 않는다.

| 의도한 단어 | 원본 전사 | 아동 모델 전사 |
|---|---|---|
| 흔들어 · 화자 1 | 한대로 | 흔들어 |
| 흔들어 · 화자 2 | 흔들로 | 흔들어 |
| 두드려 · 화자 1 | 조 뜻 | 두드려 |
| 두드려 · 화자 2 | 조드량 | 두드려 |
| 잡아 · 화자 2의 한 녹음 | 자아 | 잡아 |
| 작아 · 이전 사용자 두 녹음 | 자가 | 작아 |

기존 사용자 잡아 5개는 원본도 아/사아/장/빈 출력 등으로 실패했고 아동 모델도
접아/작아/빈 출력으로 실패했다. 따라서 이 녹음들의 실패가 아동 파인튜닝 후에만
새로 생긴 현상은 아니다. 인식 형태가 달라졌다는 사실과 정상 인식됐다는 판단은 구분한다.

`놔`는 **두 모델 모두 출력 목록에 없는 음절**이다. 파인튜닝 전후에 출력 목록을 유지했으므로
원본에서도 `놔`나 `내려놔`를 그 철자 그대로 전사할 수 없었다. 이것은 이 체크포인트와
출력 방식의 제약이며 wav2vec2라는 구조 전체가 해당 소리를 배울 수 없다는 뜻은 아니다.

## 아동 모델에서 나빠진 사례도 존재

실로폰채 2개는 원본에서 정확한 전사가 나오는 2.5초 창이 각각 한 번 이상 있었지만,
아동 모델에서는 두 녹음 모두 한 번도 정확한 철자로 출력하지 못했다.
다만 원본도 정확한 전사가 두 창 연속 나온 것은 0/2였고, 파일 전체 전사는 두 모델 모두 0/2다.

연주해는 원본에서 1/2개 녹음이 두 창 연속 정확했으나 아동 모델은 0/2였다.
들어의 파일 전체 정확한 전사는 2/6→3/6으로 늘었지만 문자 편집거리 합은 6→7로 증가했다.
따라서 평균 개선을 근거로 모든 단어의 퇴보 가능성을 부정하지 않는다.

## 기존 아동 평가와 함께 읽는 결론

[이전 아동 학습 기록](../python/tools/child_finetune/README.md)에서는 같은 dev 평가의
문자 오류율이 55.40%에서 8.71%로 감소했다. 이것은 원래부터 아동 음성을 잘못 인식하던
문제가 있었고 파인튜닝으로 상당 부분 개선됐다는 근거다. 이번의 짧은 단어·제공 화자 조건과
다르므로 두 수치를 직접 비교하거나 이번 53개의 결과를 전체 성능으로 일반화하지 않는다.

현재 근거는 다음을 지지한다.

1. 원본 모델로 되돌리면 현재 문제가 전반적으로 해결된다는 근거는 없다.
2. 원본부터 있던 출력 어휘의 제약과 일부 단어 인식 실패가 아동 모델에도 남아 있다.
3. 파인튜닝 후 좋아진 발화와 나빠진 단어·입력 창이 함께 있으므로 개별 비교가 필요하다.
4. 정확한 철자 전사, 정답 확정, 실제 발음 오류 판별을 별도 지표로 측정해야 한다.
