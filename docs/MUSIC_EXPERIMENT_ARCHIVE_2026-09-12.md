# 악기놀이 실험 보존 기록과 임시조치 전 작업 기준 · 2026-09-12

**2026-10-03 보존 상태 갱신:** 당시 사용한 글자 단위 아동 모델은
`python/tools/child_finetune/runs/child/best` 한 개만 비교용으로 남겼다.
중간 학습 가중치, 다른 음절 모델, ONNX 사본과 Unity 검증 캐시·빌드를 삭제했다.
실험 소스·설정·수치·원본 녹음·라벨은 보존했다.
[현재 보존 범위와 검증 결과](LEGACY_MODEL_CLEANUP_2026-10-03.md).
아래 절차와 외부 ZIP 보관 위치는 9월 12일 당시 기록이며, 삭제된 배포 모델·빌드를 포함한
상태가 현재도 그대로 남아 있다는 뜻은 아니다.

악기놀이 발표용 0.8.0~0.8.6의 구현과 측정 자료를 보존하고, 실행 코드와 Unity 패키지를
임시조치 전 **`5bdea00`의 0.7.0**으로 복원했다. 이후 개발은 이 기준에서 시작한다.
이 문서의 0.8.x 수치와 설정은 보관한 실험 결과이며, 복원된 0.7.0에 적용된 값이 아니다.

반복을 합치면 12개 표현이다. `/`는 표의 구분 기호다. 정답 후보는 현재 단계의 표현만
전달하며, 후보 순서도 단계 표대로 유지했다. `내려놔`는 `놔`의 포함 관계만으로 자동 허용되지
않아 별도로 등록했다. 전체 발화 조건 때문에 표준 음소를 넣어도 `내려놔`를 `놔`로 처리하지 못했다.

## 4. 마지막 두 화자 검사 결과

46개 녹음은 화자별 23개이며, 자연스러운 단어 발화로 분할하고 라벨을 붙였다.
원본 및 분할 PCM WAV를 보존했다. 문장 자료를 모은 이전 작업은 문장 전체를 유지했다.
분할 라벨은 알려진 진행 순서와 전사 결과를 이용했으며, 작업자가 직접 청취 검증한 것으로
표시하지 않았다. 사용자는 당시 실패 9개를 직접 듣고 통과해야 할 발화라고 평가했다.

검사 조건은 16 kHz 모노, 2.5초 입력 창, 0.5초 hop, 시작 지연 0/125/250/375ms다.
파일 끝은 hop에 정렬하고 1초 무음으로 마무리했다. 정답 라벨을 ASR 입력에 주지 않았고,
원음의 음량·내용을 바꾸지 않았다. 확인 횟수는 한 번 말한 소리를 반복 검사하는 횟수다.
