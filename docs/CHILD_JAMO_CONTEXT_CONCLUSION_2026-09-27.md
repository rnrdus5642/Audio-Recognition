# 무음·음량 추가 학습 판정

## 판정

**이번 설정에서는 무음·음량 변형을 추가할 이점이 확인되지 않았다. 기존의 책·나비·뛰어가요 오류를 해결한 모델은 얻지 못했고, 서비스 모델을 교체하지 않는다.**

두 가지 변형 방식, 두 번의 무작위 순서 반복, 같은 양의 원본 추가 학습 대조군을
비교했다. 대조군 2개와 변형 모델 4개를 실제로 학습하고 평가했다. 단순히 기존
모델보다 나아졌는지만 보지 않고, 추가 학습 자체의 효과와 변형의 효과를 구분했다.

이 판정은 4,096개, 마지막 8개 Transformer 층과 출력층, 2회 학습, 20ms 입력 간격에
한정한다. 더 큰 자료·다른 학습 범위에서 모든 변형 학습이 무효라는 결론은 아니다.
전층 학습 코드는 준비했지만 실행하지 않았다.

## 주 평가 결과

학습 음성과 순서·노출 수·초기 가중치·최적화 설정을 맞췄다. 기존 청취 평가 음성과
그 화자는 이번 추가 학습에서 제외했다. 검증은 원본 1,500개, 미리 정한 검증
256개×6개 변형, 기존 청취 27개×7개 조건이다. 아래 개인 음성 11개는 청취 27개의
부분집합이며 모두 골라진 개발 사례다.

| 방식 | 반복 | 원본 검증 자모 오류 / 33,182 | 변형 검증 자모 오류 / 34,650 | 개인 원본 일치 / 11 |
| --- | --- | ---: | ---: | ---: |
| 기존 모델 | — | 979 | 1,165 | 2 |
| 원본만 추가 학습 | 1 | 990 | 1,162 | 3 |
| 원본만 추가 학습 | 2 | 982 | 1,179 | 3 |
| 무음 추가·음량 변형 | 1 | 982 | 1,157 | 3 |
| 무음 추가·음량 변형 | 2 | 986 | 1,180 | 2 |
| 기존 무음 조절·음량 변형 | 1 | 981 | 1,167 | 2 |
| 기존 무음 조절·음량 변형 | 2 | 986 | 1,181 | 2 |

자모 오류는 적을수록, 개인 완전 일치는 많을수록 좋다. 6개 변형은 같은 녹음을
반복한 것이므로 1,536개의 독립 음성 표본으로 세지 않았다. 모든 방식의 변형 오류율
차이를 같은 시드의 대조군과 비교한 화자 단위 95% bootstrap 구간에는 0이 포함됐다.
사전에 정한 변형 오류 10% 감소·개인 사례 추가 개선 등의 채택 조건을 통과한 모델은 없다.

일관성과 정확성도 달랐다. 두 번째 기존 무음 조절 모델은 입력 변형에 따른 출력
변화가 기존 179회에서 161회로 줄었지만, 자모 오류는 1,165개에서 1,181개로 늘었다.
같은 오답을 더 자주 출력하는 결과를 개선으로 세지 않는다.

## 기존 사례에서 일어난 일

- `책`은 추가 학습 후 두 변형 방식 모두 `새`로 출력했다. 맞힌 결과가 아니다.
- `뛰어가요`는 계속 `귀어 가요`였다.
- `나비`는 원본만 추가 학습한 두 대조군에서 맞혔다. 무음 추가 방식은 한 번만
  맞혔고, 기존 무음 조절 방식에서는 `날비` 또는 `나리`였다. 변형 학습의 성과로
  돌릴 근거가 없고, 일부 무음 조건에서는 대조군도 다시 `나리`로 바뀌었다.
- 청취 기준 `쌕`을 모든 추가 학습 모델이 원본 조건에서 `책`으로 출력했다.
  실제 발음을 보존한다는 목표에서는 채택할 수 없는 결과다.
- 기존 추가 청취 사례의 `사워요→싸워요`, `웡충이→원숭이`,
  `누구이까요→누구일까요` 등도 남았다. 청취 표기는 단일 청취자의 잠정 판단이며
  정밀 음성학적 정답으로 승격하지 않았다.

학습용 확인 32개의 원본 오류는 첫 반복에서 6개에서 2개로 줄었다. 대조군과
기존 무음 조절 모델이 모두 이 수치였다. 가중치 업데이트와 학습 표본 적합은
진행됐으나 기존 어려운 사례로 일반화한 개선은 확인되지 않았다.

## 새로 확인한 입력 조건

선정한 4,096개 중 2,831개에는 양끝 합계 100ms 이상의 정확히 0인 여백이 있었다.
원본 길이로는 1.5초 미만이 5개였지만, 양끝 0만 제거하면 474개였다. 소리가 있는
샘플을 모두 유지하고 양끝에 가능한 80~100ms 여백과 20ms 위상을 보존하면 379개다.

4,096개 모두 원본 WAV가 모노였고, 학습 파형이 원본 디코딩 파형의 직접 슬라이스와
일치했다. **확인한 여백은 우리 전처리가 새로 붙인 것이 아니다.** 원본 자료가
제작될 때 여백이 생긴 경위나 전체 15만 개에서의 비율까지 조사한 것은 아니다.

처음에는 기존 여백에 무음을 더하기만 했다. 후속 실험은 원래의 0 여백도 조절해
1.5초 미만 입력 노출을 두 반복에서 각각 10회→295회, 10회→292회로 늘렸다.
두 반복의 총 16,384회 입력을 검사했으며 0이 아닌 샘플 제거와 CTC 정답 길이 부족은
모두 0회였다. 그 수정 후에도 주 평가에서 변형 학습의 이점은 나타나지 않았다.

이는 입력 길이의 차이가 있다는 증거다. 그 차이가 개인 음성 오류의 주원인이거나,
배경소음이 원인이라고 확정한 결과는 아니다.

## 기존 0 여백 제거 보조 검사

같은 검증 256개 중 174개에서만 신호를 보존하며 기존 0 여백을 줄일 수 있었다.
기존 모델은 이 174개에서 출력 23개가 바뀌었고 자모 오류는 116개에서 122개로
늘었다. 입력의 말소리 샘플을 바꾸지 않아도 출력이 달라지는 민감성을 재확인했다.

| 모델 | 여백을 줄인 174개의 자모 오류 / 4,053 | 자기 원본 출력과 달라진 녹음 / 174 |
| --- | ---: | ---: |
| 기존 모델 | 122 | 23 |
| 원본 추가 학습 1 | 122 | 18 |
| 무음 추가·음량 변형 1 | 122 | 18 |
| 기존 무음 조절·음량 변형 1 | 123 | 21 |
| 원본 추가 학습 2 | 125 | 20 |
| 무음 추가·음량 변형 2 | 127 | 22 |
| 기존 무음 조절·음량 변형 2 | 125 | 19 |

기존 무음 조절 모델은 같은 시드 대조군보다 한 번은 오류가 1개 많고 한 번은
같았다. 이 보조 검사에서도 개선 증거는 얻지 못했다. 변형되지 않은 82개를
포함한 전체 256개 결과와 화자 단위 불확실성도 원시 기록에 함께 남겼다.

청취 27개 중 개인 녹음 11개에는 제거 가능한 긴 0 여백이 없었다. 이 11개는
입력이 그대로였으므로 출력이 유지된 것을 새 강건성 증거로 세지 않는다.
학습과 맞춘 20ms 위상의 무음 추가 검사에서도 앞선 변형 방식의 이점은 재현되지
않았다. 주 평가에서 쓴 무음 시작 위치만 달라서 실패했다고 설명할 근거는 없다.

7개 모델 각각에서 청취 원본 27개의 재로딩 출력을 다시 확인했고 모두 이전과
일치했다. 원본 검증 예측은 PCM·평가·체크포인트 해시가 고정된 기존 평가를
재사용하고, 새로 짧아진 입력은 각각 직접 추론했다. 원본 모델 해시도 유지됐다.

## 다음 작업의 우선순위

같은 자료와 설정으로 무음·음량 학습 횟수만 늘리는 일은 우선하지 않는다.
다음 모델 실험은 **실제 발음이 확인된 짧은 발화와 자음·모음 대조를 학습하고,
다른 화자에서 그 구분이 유지되는지 검증하는 것**에 초점을 맞추는 편이 타당하다.

기존 전사형 정답과 실제 발음 표기를 구분하고, 모호한 청취 답변은 유보해야 한다.
앞선 6개 라벨 수정 학습도 새 화자 4개로 일반화하지 못했으므로, 그 몇 사례를
그대로 반복하는 확대 실험도 근거가 부족하다. 현재 결과만으로 전체 오류의 원인을
라벨 하나로 확정하지 않는다. 이미 여러 번 살펴본 개인 사례와 별도의 화자·발화로
평가할 준비를 먼저 갖춰야 한다.
