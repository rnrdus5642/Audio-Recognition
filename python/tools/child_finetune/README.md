# 아동 음성 fine-tune (2026-08-19)

`kresnik/wav2vec2-large-xlsr-korean` 을 AI Hub 아동 음성으로 재학습한
기록입니다. 성인 모델은 건드리지 않았습니다.

---

## 한 줄 결론

**dev CER 55.40% → 8.71%.** 오류가 1/6 로 줄었습니다.

제품 조건(아이가 단어 하나를 말함)에서 확정률은 **37.3% → 88.1%**, 오확정은
3.50% → 0.70% 입니다. fine-tune 만으로는 절반이고 매칭 파라미터를 새 모델에
맞추는 작업이 함께 필요했습니다 — 아래 [튜닝까지 마친 결과](#튜닝까지-마친-결과-2026-08-19).

---

## 왜 했나

파라미터 튜닝은 [child_tuning](../child_tuning/README.md) 에서 이미 상한에
닿았습니다. 아동 검출 48.7% 인데 임계값을 넘을 수 있는 케이스가 52.8% 뿐이고,
나머지 47% 는 모델이 아이 목소리를 **다른 말로 알아들어서** 어떤 설정으로도
안 잡혔습니다. 빈 출력은 0건이었습니다 — 침묵한 게 아닙니다.

| | ASR 문자 오류율 | 검출 |
|---|---|---|
| 성인 (Zeroth) | 1.7% | 87.5% |
| 아동 (AI Hub) | 55.4% | 48.7% |

같은 엔진인데 반으로 줍니다. 음향 모델 말고는 건드릴 곳이 없었습니다.

| 0 (학습 전) | 55.40% | — |

| 2 | 13.45% | −4.20pp |

| 7 | 8.95% | −0.22pp |

첫 epoch 에서 대부분이 나오고 그 뒤로는 완만합니다. epoch 6 이후는 0.2pp
수준이라 사실상 동률이고, **어느 쪽이 확정률에서 이길지는 CER 로 알 수
없습니다.** 그래서 8개를 다 남겼습니다.

같은 발화가 이렇게 바뀝니다.

```
정답  부럽습니다       학습 전  증일          후  습니다
```

## 설정

```
모델        wav2vec2-large-xlsr-korean · 24층 · 317M (학습 312M)
동결        특징추출기(CNN 7층)
정밀도      fp16
배치        패딩 포함 오디오 100초 · 누적 2
lr          3e-5 · warmup 500 · 이후 선형 감쇠
SpecAugment time 0.065 · feature 0.1   (체크포인트 기본값은 거의 꺼져 있음)
ctc_zero_infinity  True
```

```
GPU         RTX 5060 Ti 16GB
처리량       217 오디오초/초 · VRAM 10.4GB
소요         7.05시간 (8 epoch, 28,768 step)
loss        4.42 → 0.344
```

배치를 발화 개수가 아니라 **오디오 초**로 묶습니다. 길이가 1~15초로 퍼져
있어서 개수로 묶으면 패딩에 배치의 대부분을 쓰거나 긴 꼬리에서 VRAM 이
터집니다. 초로 묶으면 피크가 구조적으로 고정돼, 100 step 째나 28,000 step
째나 10.4GB 로 같았습니다.

## 데이터

```
train   123,943 발화   199.8h   화자 884명
dev         787 발화     1.4h   화자  50명
```

676시간 중 200시간만 씁니다. 그 이상은 CER 이 거의 안 내려가고 epoch 시간만
늘어납니다. 전체를 받은 이유는 시간이 아니라 **화자 수**였습니다 — 아이별
개인차가 나이 차이보다 컸습니다.

화자별 발화 수가 4개에서 1,016개까지 퍼져 있어서 무작위로 뽑으면 말 많은
아이 몇 명이 예산을 다 가져갑니다. 그래서 **화자당 상한 213 발화**로 뽑습니다.

dev 는 train 화자에서 갈랐습니다. valid/test 분할은 손대지 않았습니다 —
최종 숫자를 거기서 낼 것이라서요.

## 어휘는 늘리지 않았습니다

어휘는 음절 1205개 고정입니다. 아동 전사의 0.75% (발화 기준 11.2%) 가 여기
벗어나는데, 늘리면 출력층이 바뀌면서 모델별 `vocab.json` 분리 · 패리티 벡터
재생성 · Unity 디코더 재확인이 따라옵니다. 그대로 두면 ONNX 출력 모양도
C# 디코더도 전부 유지됩니다.

대가는 **`놔` 하나**입니다. 커리큘럼의 `놔`·`놔요` 는 정확히 발음해도 전사될
수 없습니다. 코퍼스에도 64건뿐이라 어휘를 늘려도 제대로 안 배웁니다. 어휘
문제가 아니라 단어 선정 문제입니다.

---

## 전사는 철자형 그대로 씁니다

`먹어요` 를 `머거요` 로 바꾸지 않고 넣습니다. 기기에서 `Rules.Apply` 가
돌기 때문에, 모델이 발음형을 뱉으면 규칙이 두 번 걸립니다.

AI Hub 전사가 철자형인 것은 확인했습니다. 276만 발화에서 `먹어요` 8,476건 ·
`머거요` 0건, `학교` 34,899건 · `학꾜` 0건이고, 규칙을 돌리면 93.4% 가
달라집니다.

학습 뒤에도 철자형이 유지되는지 따로 쟀습니다. 규칙이 실제로 바꾸는 발화
30개에서 출력까지의 편집거리입니다.

| | 철자형까지 | 발음형까지 |
|---|---|---|
| 학습 전 | 246 | 318 |
| epoch-05 | **56** | 214 |

유지될 뿐 아니라 더 분명해졌습니다. 기기의 규칙 경로가 그대로 유효하고,
정답 데이터도 손댈 필요가 없습니다.

## 반드시 짚어야 할 두 가지

### CER 과 확정률은 같이 움직이지 않습니다

CER 이 2배 차이나는 두 체크포인트의 확정률 차이가 3.8pp 였습니다.

| | dev CER | 확정률 |
|---|---|---|
| epoch-01 | 17.65% | 70.6% |
| best | 8.71% | 74.4% |

(오확정 1% 로 맞춘 문장 조건 기준) CER 을 8.71%에서 더 짜내도 확정률로는
1pp 미만입니다. epoch 을 늘리거나 학습 데이터를 400시간으로 키우는 것을
접은 근거입니다.

### 학습 데이터는 문장이고 제품은 단어입니다

코퍼스 발화는 중앙값 5.25초의 문장입니다. 제품은 단어 하나를 받습니다.

음향 모델 자체는 길이에 둔감해서 이 차이가 학습에는 큰 문제가 아닙니다.
문제가 되는 곳은 **임계값**입니다 — 2026-08-18 에 성인 쪽에서 문장 속 단어로
임계값을 맞췄다가 단독 단어가 깨진 적이 있습니다.

아동 쪽에는 다행히 실측 수단이 있습니다. 코퍼스에 커리큘럼 단어를 **단독으로**
말한 발화가 있습니다.

| 단어 | 화자 | | 단어 | 화자 |
|---|---|---|---|---|
| 와요 | 120 | | 먹어요 | 73 |
| 엄마 | 81 | | 책 | 67 |
| 빵 | 80 | | 할머니 | 62 |
| 우유 | 76 | | 친구 | 60 |
| 사과 | 73 | | | |

10단어 · 711발화. 성인 쪽에서 끝내 못 구한 평가셋이고, 재튜닝은 여기서
검증해야 합니다.

## 튜닝까지 마친 결과 (2026-08-19)

fine-tune 만으로는 절반입니다. 매칭 파라미터가 성인 모델이 틀리는 방식에
맞춰져 있어서, 새 모델에 그대로 쓰면 오확정이 예산의 6배가 됩니다.

test 분할, 처음 보는 아이 52명 기준입니다.

| | 단독 단어 | 덧붙임 | 오확정 |
|---|---|---|---|
| 성인 모델 + 성인 설정 | 37.3% | 48.5% | 3.50% |
| 아동 모델 + 성인 설정 | 91.3% | 91.3% | 6.47% |
| **아동 모델 + 아동 설정** | **88.1%** | **94.8%** | **0.70%** |

**단독 단어가 제품 조건입니다.** 화면에 단어를 띄우고 아이가 그 단어만
말합니다. 덧붙임은 아이가 `"사과요"` 처럼 말을 더할 때입니다.

바뀐 값은 이렇습니다.

```
skip_cost     0.05  → 0.005
커버리지        0.8   → 0.8   (유지)
문맥 배수       6.0   → 8.0
연속 확인       2회 (유지)
임계값         음소 길이별 → 단어별
matrix        ko_child_v1 → ko_child_v2 (치환 비용은 동일, 프로필만 다름)
```

### 조건을 섞으면 안 됩니다

문장으로 맞춘 값이 단독 조건에서 **88.8%** 였습니다. 성인 설정의 90.0%
보다 낮습니다. `skip_cost` 를 10배 낮춰 문장에서 11pp 를 얻었는데 제품
조건에서는 아무것도 사지 못했습니다 — 창 밖 음소에 매기는 벌점인데 단독
단어는 창 밖이 비어 있습니다.

지금 값은 검출을 단독 발화에서, 오확정을 연속 발화에서 잽니다.
`frames.py --isolated` 가 앞의 것을 만듭니다.

### 연속 확인은 1회가 더 높습니다

```
1회   단독 94.4%   오확정 0.82%
2회   단독 88.1%   오확정 0.70%
```

수치로는 1회지만 2회로 뒀습니다. 오확정을 코퍼스 발화로만 쟀고, 헤드셋
마이크가 잡을 순간적 잡음은 그 자료에 없습니다. 발음 교정 제품에서는
"안 말했는데 통과"가 더 나쁜 오류입니다. 잡음 녹음이 생기면 다시 정할
값입니다.
