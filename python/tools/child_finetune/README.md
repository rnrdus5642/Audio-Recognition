## 전사는 철자형 그대로 씁니다

`먹어요` 를 `머거요` 로 바꾸지 않고 넣습니다. 기기에서 `Rules.Apply` 가
돌기 때문에, 모델이 발음형을 뱉으면 규칙이 두 번 걸립니다.

AI Hub 전사가 철자형인 것은 확인했습니다. 276만 발화에서 `먹어요` 8,476건 ·
`머거요` 0건, `학교` 34,899건 · `학꾜` 0건이고, 규칙을 돌리면 93.4% 가

학습 뒤에도 철자형이 유지되는지 따로 쟀습니다. 규칙이 실제로 바꾸는 발화
30개에서 출력까지의 편집거리입니다.

임계값을 맞췄다가 단독 단어가 깨진 적이 있습니다.

아동 쪽에는 다행히 실측 수단이 있습니다. 코퍼스에 커리큘럼 단어를 **단독으로**

## 어휘를 넓힌 후보를 만드는 법

배포본은 손대지 않습니다. 새 디렉터리에만 씁니다.

```bash
python -m python.tools.vocab_coverage                     # 무엇이 빠졌는지
python -m python.tools.child_finetune.extend_vocab \
    --model runs/child/best --add 놔 \
    --out runs/child-vocab-0906-c4e7/init
```

`extend_vocab` 은 기존 id 를 하나도 움직이지 않습니다. 1205 뒤에 `놔` 를
붙이고, 토크나이저 전용인 `<s>`·`</s>` 는 1206·1207 로 밀려납니다. blank
1204 · unk 1203 · 구분자 859 는 그대로이고, `lm_head` 의 기존 1205행과 나머지
파라미터 423개는 비트 단위로 같습니다. 전부 임시 디렉터리에서 검증한 뒤에만
요청한 이름으로 옮깁니다.

`tokenizer.add_tokens()` + `resize_token_embeddings(len(tokenizer))` 로 하면
안 됩니다. `len(tokenizer)` 는 출력폭이 아니라 1207 이라, 새 음절이 1207 에
붙고 1205·1206 에 학습된 적 없는 문장 마커 행이 생깁니다. 그 행은 argmax 를
이길 수 있고 아무 경고도 없습니다.

학습용 manifest 는 어휘를 바꿨으면 새로 만들어야 하고, 상한 때문에 희귀
음절이 다시 빠지므로 명시적으로 남겨야 합니다.

```bash
python -m python.tools.child_finetune.manifest \
    --vocab runs/child-vocab-0906-c4e7/init \
    --keep-syllables 놔 --repeat 4 \
    --out python/tools/child_finetune/data/vocab-0906-c4e7
python -m python.tools.child_finetune.train \
    --init-model runs/child-vocab-0906-c4e7/init \
    --data python/tools/child_finetune/data/vocab-0906-c4e7 \
    --out runs/child-vocab-0906-c4e7/run
```

`data/` 와 `runs/` 는 둘 다 gitignore 되어 있습니다. manifest 에는 코퍼스
경로와 전사가 그대로 들어가므로, 새 경로를 쓸 때는 `git check-ignore` 로
먼저 확인하세요. 기존 `data/train.csv`·`data/dev.csv` 는 덮어쓰지 않습니다 -
`--vocab` 을 바꾸면 `--out` 을 요구하고, 이미 manifest 가 있는 디렉터리는
`--force` 없이는 거부합니다.

상한이 희귀 음절을 다시 떨어뜨리는 것이 핵심입니다. `--keep-syllables` 는
화자당 상한 밖에 있는 그 음절의 발화를 되살리고, `--repeat` 은 train 에서만
복제합니다. 보고는 고유 시간과 복제 포함 노출 시간을 따로 찍고, 열리지 않는
wav 을 걸러낸 **뒤에** 셉니다.

`--init-model` 은 가중치만 가져오고 옵티마이저 · 스케줄 · epoch 을 새로
시작합니다. Adam 의 모멘트는 넓어진 헤드에 맞지 않습니다. `--resume` 과 같이
쓸 수 없습니다.

## 튜닝까지 마친 결과 (2026-08-19)

fine-tune 만으로는 절반입니다. 매칭 파라미터가 성인 모델이 틀리는 방식에
맞춰져 있어서, 새 모델에 그대로 쓰면 오확정이 예산의 6배가 됩니다.

test 분할, 처음 보는 아이 52명 기준입니다.

| | 단독 단어 | 덧붙임 | 오확정 |
|---|---|---|---|
| 성인 모델 + 성인 설정 | 37.3% | 48.5% | 3.50% |
| 아동 모델 + 성인 설정 | 91.3% | 91.3% | 6.47% |
| **아동 모델 + 아동 설정** | **88.1%** | **94.8%** | **0.70%** |

**단독 단어가 제품 조건입니다.** 화면에 단어를 띄우고 아이가 그 단어만
말합니다. 덧붙임은 아이가 `"사과요"` 처럼 말을 더할 때입니다.

바뀐 값은 이렇습니다.

```
skip_cost     0.05  → 0.005
커버리지        0.8   → 0.8   (유지)
문맥 배수       6.0   → 8.0
연속 확인       2회 (유지)
임계값         음소 길이별 → 단어별
matrix        ko_child_v1 → ko_child_v2 (치환 비용은 동일, 프로필만 다름)
```

### 조건을 섞으면 안 됩니다

문장으로 맞춘 값이 단독 조건에서 **88.8%** 였습니다. 성인 설정의 90.0%
보다 낮습니다. `skip_cost` 를 10배 낮춰 문장에서 11pp 를 얻었는데 제품
조건에서는 아무것도 사지 못했습니다 — 창 밖 음소에 매기는 벌점인데 단독
단어는 창 밖이 비어 있습니다.

지금 값은 검출을 단독 발화에서, 오확정을 연속 발화에서 잽니다.
`frames.py --isolated` 가 앞의 것을 만듭니다.

### 연속 확인은 1회가 더 높습니다

```
1회   단독 94.4%   오확정 0.82%
2회   단독 88.1%   오확정 0.70%
```

수치로는 1회지만 2회로 뒀습니다. 오확정을 코퍼스 발화로만 쟀고, 헤드셋
마이크가 잡을 순간적 잡음은 그 자료에 없습니다. 발음 교정 제품에서는
"안 말했는데 통과"가 더 나쁜 오류입니다. 잡음 녹음이 생기면 다시 정할
값입니다.

`쳐`·`실로폰`·`흔들어요` 는 아직 확인되지 않았습니다.
