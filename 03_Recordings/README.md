# 직접 녹음과 검증 기록

2026-10-26 기준. 사람이 직접 녹음한 자료와 이를 나눈 클립을 찾는 폴더다.
원본 폴더는 유지하고, 프로젝트 내부에 저장된 녹음은 바로가기로 연결했다.

| 여기서 열 위치 | 자료 | 라벨 상태 |
|---|---|---|
| `아동오디오/` | 원본 MP3 4개, 전사 HWP, 단어별 WAV 83개(48+35) | 문서 전사와 발화 순서로 분할. 개별 청취 검수는 미완료 |
| `악기놀이녹음본/` | 원본 MP3·M4A 2개, 분할 WAV 46개(23+23) | 제시된 단어와 발화 순서 기준. 실제 발음의 정밀 전사는 아님 |
| `사용자_잡아작아/` | `잡아` 5개·`작아` 2개를 여는 바로가기, 검증 기록 바로가기 | 의도한 단어를 기준으로 구분 |
| `마이크 테스트 녹음.lnk` | 자모 마이크에서 저장한 WAV 77개와 대응 JSON 77개 | 모델 예측은 있으나 정답·실제 발음 라벨은 없음 |
| `청취검토 기록.lnk` | 자모 실험의 청취 페이지 자료·답변·녹음 보관 위치 | 기존 검토 기록 보존 |

`아동오디오/단어별_라벨링_20260906/검수.html`에서 아동 단어 클립을,
`악기놀이녹음본/분할_라벨링_2026-09-11/들어보기.html`에서 악기놀이 클립을 확인한다.
46개 중 실패 사례로 따로 모은 9개는 동일 파일의 사본이므로 추가 녹음으로 세지 않는다.
원본을 분할·변환한 파일도 별도 화자나 독립된 원본으로 세지 않는다.

바로가기 대상의 실제 위치는 상위 `Audio-Recognition` 기준으로 다음과 같다.

- 사용자 `잡아/작아`: `01_Project/.venv/grab-real-0910/recording-44.wav`~`recording-48.wav`, `recording-50.wav`, `recording-51.wav`.
- 마이크 녹음: `01_Project/.venv/child-jamo-web-20260916/microphone/recordings/`.
- 청취검토 기록: `01_Project/.venv/child-jamo-web-20260916/`.

위 직접 녹음은 현재 글자 모델의 `train.csv`·`dev.csv`에 포함되어 있지 않다.
일부는 이미 매칭 설정을 조정할 때 확인했으므로 새로운 최종 평가셋과는 구분한다.
현재 기본 글자 모델 마이크는 녹음을 자동 보관하지 않으며, 77개는 기존 자모 마이크의 기록이다.
